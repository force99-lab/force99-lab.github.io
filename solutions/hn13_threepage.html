车载摄像头嵌入透明介质扩大拍摄角（2026 湖南卷第13题）

2026年湖南卷 · 物理第13题（计算·10分）

车载摄像头需要有较大的拍摄角度。一摄像头由于结构限制，拍摄角度为 120°。如图，将摄像头嵌入均匀透明介质，介质截面为矩形。只考虑该截面内光线传播情况，通过空气与介质间界面的折射，可将实际拍摄角度扩大。求：

  1. 若希望几乎贴着介质表面入射的光线1能够以图示路径恰好射入摄像头，即拍摄角度扩大为 180°，求介质的折射率；
  2. 若介质折射率为 1.8，从侧后方向入射的光线2能够以图示路径折射之后发生一次全反射，然后恰好射入摄像头，求光线2 的入射角 θ 的正弦值。
原拍摄角 120° 目标扩大 180° 光线1 掠入射 i=90° 介质截面 矩形 光线2：n′ = 1.8 发生一次全反射

逐步求解（点击展开答案）

第(1)步：光线1 的几何 —— 掠入射与折射角
光线1 几乎贴着介质表面入射，故与法线夹角（入射角）i = 90°。
介质内折射光线恰好落在摄像头视场边界。视场角 120° ⇒ 半角 60°，
故介质内折射角 r = 60°（折射光线与法线夹角）。
第(2)步：折射定律求折射率 n
由折射定律 n = sin i / sin r：
n = sin90° / sin60° = 1 / (√3/2) = 2√33 ≈ 1.15。
第(3)步：光线2 在介质内的折射角
光线2 折射后经一次全反射、再恰好射入摄像头，即反射光线也落在视场边界（与法线成 60°）。
由反射对称（在顶面法线两侧对称），入射到顶面的光线与法线成 60°，故在竖直界面的折射光线与水平法线成 r′ = 30°。
第(4)步：由 n′ = 1.8 求 sinθ
由折射定律 n′ = sinθ / sin r′：
1.8 = sinθ / sin30° ⇒ sinθ = 1.8 × 0.5 = 0.9。
（即 θ ≈ 64.2°，光线2 从侧后方以较大角度斜射入介质。）
⚠️ 易错点1：掠入射的入射角是 90°
“几乎贴着表面入射”意味着光线与法线的夹角是 90°（不是 0°）。入射角、折射角一律与法线夹。sin90°=1，这是本题 n 求解的关键。
⚠️ 易错点2：折射角由几何（视场半角）定
介质内的折射角不是随便给的：光线“恰好射入”= 恰好落在视场边界，而视场角 120° 的半角为 60°，故折射角 r=60°。把几何条件（视场边界）与折射定律联立，才能解出 n。
⚠️ 易错点3：全反射的条件
全反射必须满足：① 光从光密射向光疏（介质→空气）；② 入射角大于临界角 C，且 sinC = 1/n。本题 n=1.8 时 C = arcsin(1/1.8) ≈ 33.7°，而光线在顶面的入射角 60° > C，故发生全反射。
💡 总结：光学综合题的套路
①先作规范光路图并标出各界面法线；②用几何（对称、三角形内角和）求出各角；③用折射定律 n=sinθ₁/sinθ₂ 与临界角 sinC=1/n 列式求解。“恰好射入/恰好射出”常对应“临界”或“落在边界”。
