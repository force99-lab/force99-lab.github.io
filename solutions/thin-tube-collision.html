细管类碰撞模型 · 三球弹性碰撞

2027届南京零模 · T16 · 类碰撞模型

如图所示，光滑水平桌面上放有一个质量为 m，半径为 R，内部光滑的细管；在管道内部直径两端有两个质量均为 m 的小球 A、B，管道外有一个质量 m₀ = ½m 的小球 C 以速度 v₀ 沿 O′O 的方向运动。设所有碰撞均为弹性碰撞，管道内径与小球半径均可忽略，求：

  1. 小球 C 与管道碰后瞬间，管道的速度 v₁；
  2. 碰撞后，经过时间 t，A、B 小球第一次相遇，求该过程中管的位移 x；
  3. A 小球第一次达到最大速度时在管道内的位置（用该位置与 O 点连线和 O′O 的夹角 θ 表示），A 小球每次通过管道内的该点时的速度大小 v.
m₀ = ½m A、B、管质量均为 m 细管半径 R C 沿 O′O 以 v₀ 运动 所有碰撞均为弹性碰撞 管道内径与球半径均可忽略

③ 交互式解题

m₀ = m/2  ·  m（管 + A + B）
R：细管圆环半径
v₀：C 初速，沿 O′O
v₁ = 2/3 v₀（碰后管速）
umin = -0.2222 v₀
umax = 0.6667 v₀
xmax = 1.6239 R

逐步求解（点击展开答案）

第(1)问：碰后瞬间细管速度与 C 的反弹速度
C 与管相遇时，A、B 位于与 O′O 垂直的直径两端，不参与沿 O′O 的碰撞，故碰撞的两物体就是 C（质量 m₀）与管（质量 m），碰撞过程动量、动能同时守恒：
m₀v₀ = m₀vC′ + m v₁ ，  12m₀v₀² = 12m₀vC′² + 12m v₁²
联立（或直接用弹性碰撞公式）得
v₁ = 2m₀m₀+mv₀ = 2·(m/2)m/2+mv₀ = v₁ = 2v₀/3，方向沿 O′O 向右；
vC′ = m₀−mm₀+mv₀ = −m/23m/2v₀ = −v₀/3，即 C 以 v₀/3 沿 O′O 反向弹回。
数值校核：动画关键帧中管速上界 umax = 0.66667 v₀ = 2v₀/3，与解析解一致。
第(2)问：A、B 第一次相遇时细管的位移
碰后以管内为系统：水平方向动量守恒（桌面光滑，管壁对 A、B 的力是内力），总动量恒为
3m · vcm = m₀v₀ ⟹ vcm = 2v₀/9，故任一时刻 t：xcm = 2v₀t/9。
A、B 第一次相遇时二者位置重合：xA = xB，于是
3xcm = x管 + xA + xB = x管 + 2xA。
又 A 从与 O′O 垂直的直径端点（此时坐标为 0）滑到 θ = 180° 的最左端，相对管的位移为 −R， 故 xA = x管 − R。代入：
3(x管 − R) = 3 · 2v₀t/9 = 2v₀t/9 ⟹ x管 = 2v₀t/9 + 2R/3。
数值校核：数值积分给出相遇时刻 t = 3.27666 R/v₀，管位移 x = 1.39481 R； 代入解析式 2v₀t/9 + 2R/3 = 1.39481 R，误差 2×10⁻⁶ R。
第(3)问：A 第一次速度最大的位置与之后每次经过该位置的速度
设某时刻 A 的角坐标为 θ（以 O′O 为 0，逆时针为正），A、B 相对细管的切向速率为 wA、wB， 细管对地速度为 u，R = 1（长度与速度同单位）：
vA = (u − wA sinθ, wA cosθ)，  vB = (u + wB sinθ, −wB cosθ)。
① 两个守恒式（系统 = 管 + A + B）。C 反弹后带走动量 (m/2)(−v₀/3) = −mv₀/6， 本系统动量不是 m₀v₀，而是 m₀v₀ − pC = 2mv₀/3：
  水平动量：3u + (wB − wA) sinθ = 2v₀/3 …(i)；
  动能：u² + |vA|² + |vB|² = 4v₀²/9 …(ii)。
② 对称性与一条恒等式。A、B 始终关于 O′O 轴对称（B 位于 −θ 处），故 wB = −wA，于是 |vA|² = |vB|² = u² + wA² − 2u wA sinθ。 代回 (ii) 立刻得到沿轨迹恒成立的关系式
  |vA|² + ½u² = 2v₀²/9
⟹ |vA| 最大 ⟺ 管速 u = 0（细管瞬时静止，管位移同时取极值）， u = 0。
③ 定位置。u = 0 时 (i) 化为 −2wA sinθ = 2v₀/3，即 wA = −v₀/(3 sinθ)，且此时 |vA| = |wA|； 再由恒等式 |vA|² = 2v₀²/9 得 v₀²/(9 sin²θ) = 2v₀²/9 ⟹ sin²θ = 1/2 ⟹ sinθ = √2/2。
A 沿管逆时针滑动（θ 由 90° 增大），第一次到达 sinθ = √2/2 即 θ = 135°， 即 A 位于管内与 O′O 成 45° 的位置， 此时 |vA| = √2/3 v₀（管速为零，管位移同时达到最大）。
④ 之后每次经过该位置。仍在 θ = 135°（sinθ = √2/2）处，由 (i)(ii) 同样解得 wA = −wB = ±√2/3 v₀，故 |vA|² = u² ∓ (2/3)u v₀ + 2v₀²/9。结合管速在 u ∈ [−2v₀/9, 2v₀/3] 间摆动：
第 1、3、5… 次经过该位置时 u = 4v₀/9，|vA| = √10/9 v₀； 第 2、4、6… 次经过时 u = 0，|vA| = √2/3 v₀。
数值校核：第 1 次过 45° 位置 t = 1.367 R/v₀，|vA| = 0.35136 = √10/9 v₀（此时 u = 4/9 v₀）； 第 2 次 t = 5.186 R/v₀，|vA| = 0.47141 = √2/3 v₀（此时 u ≈ 0，管位移 x = 1.6239 R 为最大）。 这正是面板④曲线上标注的两点。
⚠️ 易错点1：把 A、B 也算进碰撞对象
C 只与管（质量 m）发生沿 O′O 的弹性碰撞。碰前 A、B 位于与 O′O 垂直的直径两端， 管壁对它们的力沿半径方向、与 O′O 垂直，不会改变沿 O′O 的动量。若错把 3m 当碰撞质量， 会得到 v₁ = 2m₀v₀/(m₀+3m) = v₀/2，与仿真给出的上界 0.666 67 v₀ 不符。
⚠️ 易错点2：相遇位移算错符号
A 从垂直于 O′O 的直径端点滑到 θ = 180° 的最左端时，相对细管向 左 移动了 R， 所以 xA = x管 − R。若误写成 x管 + R， 正确结果会变成 x = 2v₀t/9 − 2R/3，与数值模拟（t = 3.2767 R/v₀ 时 x = 1.3948 R）矛盾。
⚠️ 易错点3：把"经过 45° 位置"当成"速度最大"
A 每次经过与 O′O 成 45° 的位置时速率并不相同（奇数次 √10/9 v₀、偶数次 √2/3 v₀）， 只有 第一次真正达到速度极大 的那一次（u = 0）才取 √2/3 v₀。混淆二者会误答 √10/9 v₀。
⚠️ 易错点4：把"管+A+B"的动量当成 m₀v₀
C 反弹时带走动量 (m/2)(−v₀/3) = −mv₀/6，所以碰后"管+A+B"系统的动量是 m₀v₀ − pC = mv₀/2 + mv₀/6 = 2mv₀/3，而不是 m₀v₀ = mv₀/2。 写成 3u + (wB − wA)sinθ = 2v₀（漏了 /3）时，(i)(ii) 联立无实数解： 判别式 Δ < 0，且 u = 0 会要求 sin²θ ≥ 4.5 > 1。
⚠️ 易错点5：漏掉 w_B = −w_A，把极值做成"流形上取最大"
A、B 始终关于 O′O 轴对称（B 在 −θ 处），故 wB = −wA， 由此才得到恒等式 |vA|² + ½u² = 2v₀²/9。若把 wA、wB 当独立变量、 直接在 (i)(ii) 的约束流形上求 |vA| 的最大值，会得到 2v₀/3（落在 wB = 0 的边界上）， 那是一个动力学永远到不了的状态，比真实最大值 √2/3 v₀ 大了 41%。
💡 总结1：本模型两条主线
①碰撞：单层弹性碰撞（m₀ : m）直接给出管速 2v₀/3 与 C 的 −v₀/3； ②碰撞后：管 + A + B 组成的系统水平动量守恒、动能守恒， 两条守恒律足以推出第(2)(3)问的全部结论，无需解微分方程。
💡 总结2：管速 u 的摆动范围
数值积分显示 u 在 [−2v₀/9, 2v₀/3] 间往复摆动，umax 恰为碰后瞬间的 2v₀/3， u = 0 出现在 A 第一次速度最大的时刻，此时管位移也达到最大 xmax = 1.6239 R。 系统动能恒为 (2/9)m v₀²，可随时作为校验。
💡 总结3：一条恒等式顶半个动力学
由对称性 wB = −wA ⟹ |vA| = |vB|， 动能守恒式 (ii) 立刻化为 |vA|² + ½u² = 2v₀²/9（沿轨迹恒成立）。 它一步给出三个结论：①|vA| 最大 ⟺ u = 0（管速为零、管位移最大同时发生）； ②|vA|max = √(2/9)v₀ = √2/3 v₀；③初态 u = 2v₀/3 时 |vA| = 0（A、B 确在管中静止）。 讲课时用它替代"v·a = 0"的隐晦极值条件，学生更容易接受。
