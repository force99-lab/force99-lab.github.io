原题再现

第43届预赛 · 计算题第14题（40分）
如图14a，空间中存在一个沿 z 轴正方向的均匀磁场，磁感应强度大小 B0 = 1.0×10−4 T。同时存在一个方向沿 z 轴的电场，其强度为 E = E0(1 − az)，其中 E0 = 0.50 N/C，a = 2.0 m−1。质量为 m = 1.6×10−26 kg、电荷量为 q = 1.6×10−18 C 的带电粒子，从原点 O(0,0,0) 以初速度 v0 = 1.0×104 m/s 沿 x 轴正方向射入。不计空气阻力及重力。
（1）求粒子在运动过程中的最大速度及在 z 方向上的最大位移；
（2）求粒子在 z 方向的位移随时间的变化关系，以及粒子达到 z 方向上最大位移时的 x、y 坐标；
（3）粒子能否回到原点？若能，求粒子从射入开始到第一次返回原点所用的时间；若不能，请说明理由。

物理过程拆解

两个互相独立的运动（叠加）：
① z 方向：只受电场力 Fz = qE0(1 − az)——线性回复力 ⟹ 简谐振动（平衡位置 z = 1/a）；
② xy 平面：速度 ⊥ B，只受洛伦兹力 ⟹ 匀速圆周运动（俯视顺时针，圆心 (0, −r)）。
题眼：算出两个角频率——ωE = √aqE0/m（简谐）与 ωB = qB0/m（圆周）——代入数据都等于 1.0×104 rad/s。简谐一个周期 ⟺ 圆周转一整圈 ⟹ 粒子回到原点。

第(1)(2)问 · 规范解答

图14a（原题图）
数值备查
ωE = ωB = 1.0×104 rad/s
r = mv0/(qB0) = 1.0 m
vz max = √qE0/(ma) = 5×103 m/s
① z 方向：电场力 Fz = qE0(1 − az)，由动能定理求 vz∫₀z qE0(1 − az′)dz′ = ½mvz2 ⟹ vz2 = qE0ma·az(2 − az)
② (1) 最大速度：vz 最大在 az = 1（即 z = 0.5 m）vz max = √qE0/(ma) = 5×103 m/s；xy 方向速率不变 v0
∴ vmax = √v02 + vz max2 = √1.25×108 ≈ 1.1×104 m/s
③ (1) z 方向最大位移：vz = 0 处，az = 2zmax = 2/a = 1.0 m（电场在 z = 1/a 处反向，速度减为零）
④ (2) z(t)：线性回复力 → 简谐振动m·d²z/dt² = qE0(1 − az) = −aqE0(z − 1/a)
ωE = √aqE0/m，z(0)=0、ż(0)=0 ⟹ z(t) = 1a(1 − cos ωEt)
⑤ z 最大时（ωEt = π）的 x、y 坐标洛伦兹力匀速圆周：ωB = qB0/m，r = mv0/(qB0) = 1.0 m
洛伦兹力初方向沿 −y ⟹ 圆心 (0, −r)、俯视顺时针；ωEt = π 时转过半圆：
x = 0，y = −2r = −2.0 m
⚠ 易错警示

① 电场是位置线性变化的变力，不能当匀强场用运动学公式；识别"线性回复力 ⟹ 简谐"是关键。

② 圆周旋转方向：q > 0、v ∥ +x、B ∥ +z，洛伦兹力 qv×B 沿 −y——圆心在 y 负半轴，y 坐标才是 −2r；方向搞反就丢一半分。

③ z 最大位移 (1.0 m) 与 vz 最大位置 (0.5 m) 是两个不同位置，别混。

✔ 自检（点击展开）

① 量纲：ωE = √aqE0/m，单位 √(m⁻¹·C·N·C⁻¹)/kg = s⁻¹ ✓

② z(t)∈[0, 2/a]，最大 1.0 m 与 (1) 一致 ✓

③ z 最大时 ż = 0，速率恰为 v₀（全部回到 xy 分量），此后折返 ✓

第(3)问 · 规范解答

图14a（原题图）
题眼
比较两个角频率：
ωE = √aqE0/m
ωB = qB0/m
代入数据恰好相等（均为 1.0×104 rad/s）。
① z 回到 0 所需时间z(t) = (1/a)(1 − cos ωEt) = 0 ⟹ ωEt = 2π，即 t = 2π/ωE（一个简谐周期）
② 同一时间内 xy 圆周转过的角度θ = ωB·t = 2π·(ωB/ωE) = 2π —— 恰好一整圈（因 ωE = ωB）
③ 结论z 回到 0 与 xy 转回原位同时发生 ⟹ 粒子能回到原点
t = 2π/ωB = 2π×10−4 s ≈ 6.3×10−4 s（与官方评分标准一致）
⚠ 易错警示

① 三个运动分量的时间必须"对表"：z 的周期与圆周周期分别算，再比较——本题它们恰好相等，这是数据的精心设计，不是普遍结论。

② 若 ωE ≠ ωB，粒子一般回不到原点（轨迹是展开的螺旋摆线），理由要说清楚。

③ 电场反向后（z > 1/a）电场力指向 −z，别误以为粒子"飞走"。

✔ 反事实检验（点击展开）

假如 B0 = 2.0×10−4 T，则 ωB = 2ωE：z 回零时圆周已转两圈——仍是原点！但若 ωB/ωE 为无理数比（如 B0=1.3×10−4 T），则永不回原点。

可见"能否回原点"由频率比是否为整数（或特定有理数）决定——这是利萨如图像思想。

方法沉淀

① 线性变力 ⟹ 简谐

凡力满足 F = −kξ（ξ 为对某平衡位置的偏离），运动必为简谐振动，ω = √k/m。

本题：Fz = qE0(1−az) = −(aqE0)(z − 1/a)，k = aqE0，平衡位置 z = 1/a。

识别比硬积分快；初始条件定出 z(t) = (1/a)(1−cos ωt)。

② 洛伦兹圆周三件套

ωB = qB0/m（与速率无关）；r = mv/(qB0)；周期 T = 2πm/(qB0)。

方向判断：F = qv×B，本题初力沿 −y ⟹ 圆心 (0, −r)、顺时针。

③ 合运动"对表"法

两个独立分运动能否"重逢"，比较它们的周期比：整数比 ⟹ 闭合轨迹（利萨如思想）。

本题 ωE:ωB = 1:1，一个周期后同时归位 ⟹ 回原点，t = 6.3×10−4 s。

答案汇总：vmax ≈ 1.1×104 m/s　　zmax = 1.0 m　　z(t) = (1/a)(1−cos ωEt)　　x=0、y=−2.0 m　　能回原点，t ≈ 6.3×10−4 s
