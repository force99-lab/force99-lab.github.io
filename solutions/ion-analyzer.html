离子分析器原理

复合场 · 带电粒子运动 · 高考压轴

某离子分析器的原理示意图如图所示，分析器由分布在 y 轴左侧的偏转区 和 y 轴右侧的检测区 组成。在直线 x=-l₀ 和 y 轴之间的偏转区内存在着两个等大反向的有界匀强电场，其中 x 轴上方的电场沿 y 轴负方向，x 轴下方的电场沿 y 轴正方向。

在 y 轴右侧检测区内分布着垂直于 xOy 平面向里、范围足够大的磁场，磁感应强度大小 B 随位置坐标 x 均匀变化，且满足 B=B₀+kx（k 为大于零的常量）。在电场左边界上点 A(-l₀,-l₀/2) 到点 C(-l₀,0) 区间内存在一线状离子源，离子源各处都能持续发射电荷量为 +q、质量为 m 的相同离子，所有离子均以相同速度 v₀ 沿 x 轴正方向射入电场。

已知从点 A 发出的离子恰好能从点 A′(0,l₀/2) 沿 x 轴正方向进入磁场，其轨迹如图中虚线所示。在检测区有一块与 y 轴平行的检测板，打到检测板的离子会被板吸收。忽略电磁场间的相互影响，不计离子的重力及它们之间的相互作用。

求：

  1. 匀强电场的电场强度大小 E；
  2. 从 AC 间某些位置发出的离子进入磁场时也能沿 x 轴正方向运动，写出这些位置的 y 坐标；
  3. 若检测板可沿 x 轴平移，要使检测板能收集到沿 x 轴正方向进入磁场并经磁场偏转后的所有离子。
    ① 求检测板位置坐标 x 的最大值；
    ② 当检测板位置坐标 x 取最大值时，测得从点 A′(0,l₀/2) 进入磁场的离子在检测板上的收集点到 x 轴的距离为 h+l₀/2，求该离子在磁场中的运动轨迹与坐标轴和检测板所围图形面积的大小。
离子：+q，m 初速度：v₀ 沿 +x 电场：x∈[-l₀,0]，上下反向 磁场：B=B₀+kx（向里） 检测板：x=x_max，竖直

③ 交互式解题

源区：A(-l₀,-l₀/2) ~ C(-l₀,0)
电场区：-l₀ ≤ x ≤ 0
磁场区：x > 0，B=B₀+kx
关键：电场关于 x 轴镜像反向

逐步求解（点击展开答案）

第(1)问：求匀强电场强度 E

建模：从 A 到 A′，x 方向匀速运动，总时间 t=l₀/v₀；y 方向先向上匀加速（下半区），再向上匀减速（上半区），由于加速度大小相等、方向相反，末速度回到 0。

y 方向 v-t 图：三角形，底 t、面积等于 y 位移 l₀，故最大 y 速度 vy,max=2l₀/t=2v₀。

vy,max = a·t2 = qEm·l₀2v₀ = 2v₀

解得：

E = 4mv₀²ql₀
第(2)问：还能沿 +x 出电场的源位置

对称性分析：离子在电场中做一系列振幅为 d 的“抛物线拱”。每半个拱的水平跨度 x₁=v₀√(2d/a)。

出射条件：离子到达 x=0 时恰好处于速度为 0 的转折点，则总水平距离需满足

l₀ = 2n x₁， n=1,2,3,…（n 为整数序号）

代入 a=qE/m=4v₀²/l₀ 得 d=l₀/(2n²)。

源位置 y 坐标：

y = -l₀2n²， n=1,2,3,…

（n=1 即为 A 点；n=2,3,… 给出其余位置。）

第(3)问①：检测板最大 x 坐标

建模：离子以 v₀ 沿 +x 进入磁场 B=B₀+kx。洛伦兹力始终垂直速度，速率不变。

y 方向动量定理：Fy=qvₓB，且 vₓdt=dx，故

∫0x_max qB(x)dx = mv₀

代入 B=B₀+kx：

q(B₀x_max + 12kx_max²) = mv₀

解得：

x_max = -B₀ + √(B₀² + 2mkv₀q)k

取正根。

第(3)问②：轨迹与坐标轴、检测板围成面积

① 用正则动量守恒一步定出 vy(x)（不写 dy/dx 的轨道积分）

因 B=B(x) 只依赖 x、与 y 无关，体系沿 y 方向平移对称 ⇒ 正则动量守恒：

py + qAy = 常量，其中矢势 Ay(x) = −∫0xB dx′ = −(B₀x + 12kx²)

入射点处 vy=0、Ay=0，故全程常量为零，得

mvy(x) = q(B₀x + 12kx²) ⟹ vy(x) = qm(B₀x + 12kx²)

高中写法（与上式等价，不需积分符号）：取 x 处一小段，Δ(mvy) = qvxB·Δt = qB·Δx，沿 x 逐段累加即得同一结果。①问的 x_max 正是令终点 vy=v₀（即 vx=0）得到的。

② 面积用“矩形互补”，不必先求 y(x) 的解析式

所求面积由 x 轴、y 轴、检测板 x=x_max 与轨迹围成。把大矩形沿轨迹切成互补的两块（图中两块交替高亮）：

S = (y入+h)·x_max − S左，其中 y入 = l₀2，S左 = ∫0x_max x dy

曲线左边这块面积按 y 累加最方便：每个微元 Δy = vyvx·Δx，而 vx=√(v₀²−vy²)，vy 已由正则动量给出（是 x 的二次函数）。

高中处理：把 [0, x_max] 等分成 n 份，逐格求 Δy 与对应的 x·Δy 再求和（分割—求和—取极限，即微元法；有具体数值时直接数格子累加）。

S左 ≈ Σ xi·vy(xi)√(v₀²−vy²(xi))·Δx

说明：k≠0 时轨迹不是圆弧，这块面积一般没有初等闭式——这正是题目直接给出实测值 h+l₀/2 的原因，用它配合①问的 x_max 即可锁定矩形部分，余下曲边部分用上面的分割求和得到数值。若 k=0（匀强磁场），轨迹退化为四分之一圆弧，S 才有几何闭式。

③ 微元怎么切：竖切（y·Δx）还是横切（x·Δy）？

竖切：沿 x 方向切竖条，宽 Δx、高 y，加总得曲线下方到 x 轴的面积，即 S = Σ y·Δx ——但要先知道轨迹方程 y(x)，本题 y(x) 无解析式，此路不通。

横切：沿 y 方向切横条，高 Δy、宽 x，加总得曲线左侧到 y 轴的面积，即 S左 = Σ x·Δy。关键在于 ΔyΔx = vyvx，于是微元可写成 x·vyvx·Δx —— vy(x) 由正则动量直接给出，不必求 y(x)，每个微元都能算。

Σ y·Δx + Σ x·Δy = x_max·(l₀2+h)（两块互补，即分部积分 ∫y dx + ∫x dy = [xy]）

结论：选微元的原则是用已知量（速度比 vy/vx）构造，绕开未知的 y(x)；先横切算出 S左，再用矩形减回 S。注意这两块是曲线两侧不同的面积，不是同一块。

⚠️ 易错点1：把电场当成一个匀强电场
偏转区是两个等大反向的匀强电场，x 轴上方 E 向下、下方 E 向上。离子穿过 x 轴时加速度反向，是“分段类平抛”，不是单一抛物线。
⚠️ 易错点2：磁场中当作匀速圆周运动
B=B₀+kx 随 x 变化，轨迹半径 ρ=mv/(qB) 也随 x 减小，不是圆弧。求 x_max 要用动量定理积分，不能直接用 r=mv/qB。
⚠️ 易错点3：速度方向与洛伦兹力方向
正离子沿 +x 进入向里磁场，洛伦兹力初始向上（左手定则），粒子向上偏转。在 x_max 处 vₓ=0，v_y=+v₀。
💡 经验总结
① 分段场问题先画“场区分界线”，每段单独列运动方程。
② 利用对称性：反向等大电场使 y 方向速度“先加后减”，回到水平。
③ B=B(x) 的磁场，正则动量 p_y+ qA_y=0 是常用技巧，可快速得到 v_y(x)。
④ 求 x_max 用动量定理 ∫qB dx = mΔv_y，避免复杂轨迹积分。
⑤ 求围成面积先想"怎么切"：竖切 y·Δx 要先知道轨迹方程 y(x)（本题无解析式，行不通）；横切 x·Δy 可用速度比 Δy=(v_y/v_x)Δx 直接构造微元，算出 S左 后用矩形互补减回 S。
