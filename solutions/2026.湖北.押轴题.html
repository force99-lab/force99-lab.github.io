带电粒子在电场与磁场中的往复运动

图　电场·磁场往复运动示意图

如图所示，在 xOy 平面内，y>0 区域存在匀强电场，电场强度大小为 E、方向沿 y 轴负方向；在 y<0 区域，有一个以 O 为圆心、r 为半径的半圆形区域，半圆形区域内既无电场也无磁场，半圆形区域外存在匀强磁场，磁场方向垂直于 xOy 平面向里。

一质量为 m、电荷量为 q 的带正电粒子从坐标为 (0, 25r/12) 的 M 点静止释放，之后从坐标为 (2r, 0) 的 N 点第一次射出磁场。不计重力，求：

  1. 粒子第一次进入磁场时的速度大小；
  2. 磁场的磁感应强度大小；
  3. 粒子第二次射出磁场时的位置坐标。

（1）粒子第一次进入磁场时的速度大小

粒子在 y>0 的匀强电场中从静止释放，做什么运动？用哪个定理直接求末速度最方便？
步骤：电场力做功 → 动能定理

粒子从 M(0,25r/12) 在电场中向下加速，到达 y=0（进入无场区前）电场力做功为 qE·(25r/12)：

👆 点击显示动能定理方程 qE·(25r/12) = ½mv₁²
👆 点击显示速度结果 v₁ = √(2·qE·25r/12 / m) = √(25qEr / 6m)
✅ 第(1)问：v₁ = √(25qEr / 6m)
2

（2）磁场的磁感应强度大小 B

粒子在磁场中做匀速圆周运动，什么力提供向心力？轨迹的圆心和半径如何用几何关系求出？
步骤一：几何关系求轨迹半径 R

粒子从 (0,−r) 进入磁场（速度竖直向下），到 N(2r,0) 第一次射出。设轨迹圆心在 (R, −r)，由两点到圆心距离相等：

👆 点击显示几何关系 R² = (2r−R)² + r²  ⇒  R = 5r/4
步骤二：洛伦兹力提供向心力
👆 点击显示圆周运动方程 qv₁B = mv₁² / R  ⇒  B = mv₁ / (qR)
👆 点击显示 B 结果 B = m√(25qEr/6m) / (q·5r/4) = √(8mE / 3qr)
✅ 第(2)问：B = √(8mE / 3qr)
3

（3）粒子第二次射出磁场时的位置坐标

粒子从 N 点射出后进入电场，做什么运动？如何分解速度？能否利用对称性直接写出结果？
步骤一：N 点速度分解

由轨迹几何，N 点速度方向与 x 轴夹角为 θ，满足 tanθ = 4/3，因此：

👆 点击显示速度分量 vₓ = −4v₁/5，  v_y = 3v₁/5
步骤二：电场中的类斜抛运动

x 方向匀速，y 方向做类竖直上抛（加速度 −qE/m）。由对称性，回到 y=0 时 v_y 大小不变、方向反向，x 方向位移为：

👆 点击显示 x 方向位移 Δx = vₓ·(2v_y / (qE/m)) = −4v₁/5 · 6v₁m/(5qE) = −4r

💬 即从 N(2r,0) 回到 (−2r,0) 再次进入磁场。

步骤三：利用轨迹对称性
👆 点击显示对称结论 两段磁场轨迹关于 y 轴对称 ⇒ 第二次出磁场位置 = 第一次进磁场位置 = (0, −r)
✅ 第(3)问：(0, −r)

⚠️ 易错警示▸ 点击展开

❌ 误以为粒子直接进磁场
粒子先穿过无场半圆区，到达 (0,−r) 时速度才竖直向下，此时才进入磁场。位移要先算到 y=0。
❌ 磁场"向里"画图错
B 向里应画"×"。+q、速度向下、B 向里，由左手定则洛伦兹力向右，轨迹向右弯（逆时针）。
❌ 把轨迹半径当成 r
轨迹圆心不在 O！由几何 R²=(2r−R)²+r² 解得 R=5r/4，圆心在 (5r/4,−r)。
❌ 第(3)问重复硬算
对称性是捷径：两段磁场轨迹关于 y 轴对称，第二次出磁场点 = 第一次进磁场点 (0,−r)。
❌ 类斜抛符号搞反
电场方向 −y，故 y 方向加速度向下。向上运动时减速、向下运动时加速，注意 v_y 正负。
❌ 第(1)问位移取错
电场做功位移是 25r/12（从 M 到 y=0），不是 r、2r 或 25r/12−r。

💡 经验总结▸ 点击展开

🎯 分段处理法
电场加速（动能定理）→ 磁场偏转（圆周运动）→ 无场/电场过渡（抛体），逐段建模。
🎯 几何是磁场题的灵魂
画圆心、标半径、用弦长/切线关系列方程。本题 R=5r/4 是关键。
🎯 对称性是高考利器
往复/周期类问题，先算一段、再用对称推广，避免重复计算。
🎯 类斜抛分解
x 匀速、y 匀变（类竖直上抛）。回到同一高度时竖直分速度等大反向。
🎯 洛伦兹力特点
永远垂直速度 ⇒ 只改变方向、不改速率；圆周运动半径 R=mv/qB。
🎯 解题核查清单
✅ 场区边界画清 ✅ 进/出点速度方向 ✅ 圆心与半径 ✅ 对称性能否用
