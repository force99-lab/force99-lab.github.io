原题再现

第43届预赛 · 计算题第12题（40分）
当带电粒子从弱磁场区域向强磁场区域运动时，在某些条件下会被"反射"回来（磁镜效应）。考虑一个理想化的关于 z 轴对称的磁镜磁场，其示意图如图12a所示：磁场沿 z 轴方向缓慢增强，在 z 轴附近的磁感应强度的 z 分量的形式为 Bz = B0 + kz（k > 0 且很小）。一质量为 m、电荷量为 q（q > 0）的粒子，从原点 O 附近以初速度 v0（远小于光速）射入，速度方向与 z 轴正方向的夹角为 θ0（0 < θ0 < 90°）。此后，粒子在每个回旋周期内可视为绕 z 轴做近似闭合的回旋运动，粒子离开或趋近 z 轴的径向速度分量远小于其环绕 z 轴的速度分量。每个回旋轨道包围的磁通量近似相等，不计重力。
（1）记粒子速度垂直于 z 轴的分量的太小为 v1，求粒子在每个回旋周期内近似做圆周运动的半径 r（用 v1、Bz、m 和 q 表示）；
（2）证明，在题给条件下，粒子在运动过程中，其磁矩 μ = mv122Bz 近似为常量；
（3）若粒子在 z = L 处被"反射"，求 θ0 的正弦以及粒子从出发到返回至 z = 0 平面所需的时间。

物理过程拆解

运动的分解（浸渐近似）：
① 快运动：绕 z 轴的回旋（圆周），半径 r = mv1/(qBz)；
② 慢运动：沿 z 轴的"往返"——由磁矩守恒 + 能量守恒决定；
③ 题给钥匙：每个回旋轨道包围的磁通量 Φ = Bz·πr² ≈ 常量（浸渐不变量）。
磁镜效应的本质：粒子进入强场区 ⟹ 由 Φ 守恒 r 收紧 ⟹ v12 ∝ Bz 增大 ⟹ 动能守恒迫使纵向速度 vz 减小 ⟹ vz = 0 处"反射"。磁场强处"转小圈、横速大"，正是动画里螺旋收紧的样子。

第(1)(2)问 · 规范解答

图12a（原题图）
两件套
洛伦兹力提供向心力：
qv1Bz = mv12/r
磁通量：Φ = Bz·πr² ≈ 常量
① (1) 洛伦兹力充当向心力qv1Bz = mv12/r
r = mv1qBz（官方式3）
② (2) 先算磁矩的定义值回旋电流 I = qT，T = 2πrv1
μ = I·πr² = qTπr² = qv1r2 = mv122Bz（官方式5）
③ 用磁通量条件收尾Φ = Bzπr² = Bzπ·m2v12q2Bz2 = πm2v12q2Bz ≈ 常量
⟹ v12/Bz ≈ 常量 ⟹ μ = mv122Bz ≈ 常量　∎
⚠ 易错警示

① r 中的速度是垂直 z 轴的分量 v₁，不是总速率 v₀。

② 磁矩不要与"磁通量"混写：μ = I·面积（电流×面积），Φ = B·面积；本题两者通过 r 关联。

③ "磁通量≈常量"是题目给定的浸渐条件（B 缓变），不是对所有磁场都成立。

✔ 物理直觉（点击展开）

μ = mv₁²/(2B_z) 恰是"垂直方向动能 / 磁场强度"。带电粒子在缓变磁场中 μ 不变，等价于"横向动能 ∝ B"——这就是磁镜能把纵向动能"挤"成横向动能的机制。

第(3)问 · 规范解答

图12a（原题图）
两条守恒
① 磁矩守恒：v12Bz ≈ 常量
② 能量守恒：vz2+v12 = v02
初值：v10 = v0sinθ0，Bz(0) = B0
① 由磁矩守恒写出 v1(z)v12(z)B0+kz = v02sin2θ0B0 ⟹ v12(z) = v02sin2θ0·B0+kzB0
② 能量守恒 ⟹ vz2 是 z 的线性函数vz2 = v02 − v12(z) = v02cos2θ0 − kv02sin2θ0B0·z
vz2 随 z 线性减小 ⟺ z 方向匀减速，加速度大小 a = kv02sin2θ02B0
③ 反射条件 vz(L) = 0v02cos2θ0 = kv02sin2θ0B0L ⟹ tan2θ0 = B0kL
sinθ0 = √B0B0+kL（官方式13）
④ 往返时间：去程 t1 = v0cosθ0/a，返回对称t = 2t1 = 2v0cosθ0a = 4B0cosθ0kv0sin2θ0；代入 sinθ0 化简：
t = 4v0√L(B0+kL)k（官方式20）
⚠ 易错警示

① vz2 对 z 线性 ⟹ 匀减速；若按"变加速度"硬积分会绕远——识别"平方量线性"就是匀变速。

② 反射点在 z = L（Bz = B0+kL 处 vz = 0），不是"磁场最强处"自动反射。

③ sinθ₀ 表达式带根号：sinθ₀ = √B0/(B0+kL)，k→0 时 sinθ₀→1（θ₀→90°，纯横向才反射）——弱场不反射，合理。

✔ 自检（点击展开）

① 量纲：t = (4/v₀)·√L(B₀+kL)/k，根号内单位 = m·T/(T/m) = m² ⟹ √ 后为 m，除以 m/s 得 s ✓

② 极限 k→0：sinθ₀→1、t→∞——没有磁场梯度就没有磁镜，粒子一去不返 ✓

③ θ₀→90°（纯横向）：cosθ₀→0，v_z 恒为 0，粒子原地回旋不前进 ✓

方法沉淀

① 浸渐不变量思想

参数缓慢变化时，某些量的组合近似守恒：本题 Φ = Bzπr² ≈ 常量 ⟹ μ = mv₁²/(2Bz) 守恒。

这是等离子体物理与磁约束核聚变的基础之一。

② "平方量线性 = 匀变速"

守恒式整理出 v² = v₀² − 2az 的形式，即刻判定匀变速，直接用运动学公式求时间，避免积分。

本题：vz2 = v02cos2θ0 − (kv₀²sin²θ₀/B₀)·z。

③ 磁镜的应用地图

地球辐射带（范艾伦带）、托卡马克磁约束、磁瓶捕陷宇宙线——都是"两端场强、中间场弱"的磁镜位形。

反射条件（损失锥）：sin²θ₀ > B₀/Bmax 的粒子才能被约束。

答案汇总：r = mv1qBz　　μ = mv122Bz ≈ 常量　　sinθ0 = √B0B0+kL　　t = 4v0√L(B0+kL)k
