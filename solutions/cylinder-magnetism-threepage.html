通电圆筒：磁场与受力

2025 · 湖州二模 · 多选题 · 磁场矢量合成

（2025 · 湖州二模）在无限长通电直导线周围某点产生的磁感应强度 B 与距离 r 的一次方成反比，可表示为 B = kI/r。现有一半径为 R 的薄壁长圆筒如图甲所示，其壁上电流大小为 I₀。

在筒内侧的磁感应强度处处为 0，筒外侧磁场可等效为位于圆筒中心、电流强度为 I₀ 的长直导线所产生的磁场。下列说法中，正确的有（　）

  1. A. 圆筒侧壁单位面积受到的压力为 kI₀²2πR²
  2. B. 圆筒左半侧在 O 点产生的磁感应强度垂直纸面向里
  3. C. 若在圆筒外侧同轴心放置一逆时针的圆形电流如图乙所示，则圆形电流受到圆筒的吸引力
  4. D. 若在圆筒轴线放置一反向电流也为 I₀ 的长直细导线如图丙所示，则圆筒侧壁单位面积的受力为 kI₀²4πR²

逐步求解（点击展开答案）

① 先建模型：筒壁是「面电流」，它自己产生的场不能算在自己头上
把筒壁看成沿圆周均匀分布的轴向电流，面电流密度
K = I₀2πR　（总电流 I₀ 铺在周长 2πR 上）
紧邻筒壁两侧：B 内 = 0（题给），B 外 = kI₀R（等效中心导线）。
电流丝所在处的有效场必须剔除自场，取两侧矢量平均：
B 有效 = B 内 + B 外2 = kI₀2R
这就是矢量合成的第一个落点：不是代数平均数字，而是两侧场矢量相加再折半。
② A 选项：侧壁单位面积的压力是多少？
安培力（单位面积）= K × B 有效，方向 K(+Y) × B(环向) = −r̂，指向轴 → 压力。
f = K · B 有效 = I₀2πR × kI₀2R = kI₀²4πR²
A 给出 kI₀²2πR²，恰为 2 倍——错在把筒外全值 B 外 直接当成壁处场，漏了「取平均」。
A 错误 ✗
③ B 选项：左半侧在 O 点产生的磁场朝哪边？
把筒壁离散成 N 根电流丝，每根在 O 产生 dB = k·dI/R，方向垂直于「丝 → O」连线（动画页①的放射箭头）。
矢量合成看方向：左半圆各 dB 的水平分量两两抵消，垂直纸面分量同向叠加：
B 左半 = kI₀πR　垂直纸面向里（⊗）
右半圆等大反向（⊙ 向外），故 B 左 + B 右 = 0，与「筒内 B 处处为 0」自洽。
B 正确 ✓
④ C 选项：筒外同轴圆形电流会不会被吸引？
筒外场是环向（绕轴的圆周方向）；同轴圆形电流的电流元 dl 也是环向。两者处处平行：
dF = I · dl × B = I·dl·B·sin 0° = 0
逐点安培力为零，既不吸引也不排斥。「同轴」≠「相吸」。
C 错误 ✗
⑤ D 选项：轴线加一根反向电流 −I₀ 后，受力变多少？
用场矢量叠加分别看两侧：
· 筒外：B 壁(+φ) 与 B 线(−φ) 等大反向 → 相消为 0（净包围电流 −I₀+I₀ = 0）；
· 筒内：只剩轴线导线的 B 线 = kI₀R。
壁处有效场再次取平均：
B 有效 = kI₀/R + 02 = kI₀2R
f = K · B 有效 = kI₀²4πR²
与 D 给出的数值一致（方向由压力变为向外张力，但题目只问大小）。
D 正确 ✓
⑥ 结论
正确选项为 B、D。
全题只考两件事：磁场矢量合成（分解—叠加—闭合） 与 面电流处的平均场。
⚠️ 易错点1：壁电流处的场要「取平均」
电流丝不能感受自己的场。壁处有效场 = (B 内 + B 外)/2。若直接代 B 外 = kI₀/R，压力会算成 2 倍，正好是 A 选项设的陷阱。这是「自场剔除」，也是安培力计算的通法。
⚠️ 易错点2：矢量合成先看方向
全筒在 O 点 B = 0，不代表半侧为 0。左/右半侧各贡献 kI₀/(πR) 且方向相反；把 16 个 dB 首尾相接会闭合成环，合矢量才是 0。标量相加或只比大小都会判错 B。
⚠️ 易错点3：平行不产生安培力
筒外 B 是环向，同轴圆环电流的 dl 也是环向，dl × B = 0。C 选项用「同轴 + 电流」诱导学生联想「同向电流相吸」，但那要求两段电流互相平行且场垂直电流，本题不满足。
💡 总结：两条主线
主线一 · 矢量合成：把连续分布的电流离散成电流丝 → 逐根写 dB → 首尾相接/平行四边形叠加 → 得合场。用于 B（半筒合成）与题给「筒内 B = 0」。
主线二 · 平均场：面电流处 B 有效 = (B 内 + B 外)/2 → f = K·B 有效。用于 A 与 D；加反向轴线电流只是把「筒外相消、筒内相加」，平均后大小不变。
答案：BD
