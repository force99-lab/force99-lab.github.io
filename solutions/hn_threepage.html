电磁感应·储能器与导轨单杆开关电路（2026 湖南高考第14题）

2026年湖南高考 · 物理第14题（计算·14分）

某小组制作了一储能器，其两端电压 U 与其储存的电荷量 q 间的函数关系近似为 U = kq（k 为常量）。将该储能器接入如图所示电路，a、b、c 为固定的三个触点。两足够长的平行金属导轨固定于水平面上，电阻不计，间距为 L。导轨间有竖直向下的匀强磁场，磁感应强度为 B。质量为 m 的导体棒垂直导轨放置，接入电路的阻值为 r。电源电动势为 E，内阻不计。定值电阻阻值为 R。t₀ 时刻开关 S 与 a 连接，直到导体棒做匀速运动，再于 t₁ 时刻切换开关与 b 或 c 连接。运动过程中导体棒与导轨始终垂直且接触良好，忽略摩擦。求：

  1. t₀ 时刻导体棒加速度 a₀ 的大小；
  2. 若 t₁ 时刻开关与 b 连接，储能器接入电路前电压为 0，当储能器电压为 U₀ 时（此时电路中电流不为 0），求导体棒速度 v 的大小；
  3. 若 t₁ 时刻开关与 c 连接，求从 t₀ 时刻起到导体棒静止的过程中，导体棒上产生的焦耳热 Q。
导轨间距 L，B（竖直向下） 导体棒 m，电阻 r 电源 E（内阻 0），定值电阻 R 储能器 U = kq

逐步求解（点击展开答案）

第(1)步：t₀ 时刻加速度 a₀（S=a 直连电池）
t₀ 时刻棒初速度为 0，感应电动势为 0，电路中电流由电源电动势决定：
I = E/r（电流经导体棒）。
安培力 F = BIL = BELr。由牛顿第二定律 F = ma₀：
a₀ = BELmr。
第(2)步：匀速速度 v₀ 与储能器充电（S=b）
接 a 阶段末，棒匀速：安培力为 0 ⇒ 电流为 0 ⇒ 感应电动势 = 电源电动势：
E = BLv₀ ⇒ v₀ = EBL。
接 b 后电池断开，储能器 U=kq 接入。棒仍以 v₀ 运动，因 BLv₀ > U（电流不为 0），回路电流对棒产生制动安培力；储能器电压从 0 升到 U₀，储存电荷 q = U₀/k。
对棒用动量定理（取运动方向为正）：−BIL·Δt = m(v − v₀)，其中流过棒的电荷 Δq = I·Δt = q = U₀/k。
⇒ −BL·(U₀/k) = m(v − E/(BL)) ⇒ v = EBL − BLU₀mk。
第(3)步：a 阶段棒上焦耳热 Q₁
t₀→t₁（开关 a）：对棒动量定理 BIL·Δt = mv₀，流过棒（及电源）电荷 q' = mv₀/(BL) = mEB²L²。
电源输出能量 = 棒动能增量 + 棒上（电阻 r）焦耳热：
Q₁ = E·q' − ½mv₀² = E·mEB²L² − ½m(E/(BL))² = mE²2B²L²。
第(4)步：c 阶段棒上焦耳热 Q₂
t₁→静止（开关 c）：棒与 R、r 成回路，安培力做负功，动能全部转为焦耳热。
总焦耳热 Q_总 = ½mv₀² = mE²2B²L²。
串联电路中焦耳热与电阻成正比，棒（电阻 r）分得：
Q₂ = [r/(R+r)]·Q_总 = r·mE²(R+r)·2B²L²。
第(5)步：棒上总焦耳热 Q
棒上总焦耳热 Q = Q₁ + Q₂ = mE²2B²L² + r·mE²(R+r)·2B²L²
= ½mv₀²·[1 + r/(R+r)] = ½m(E/(BL))²·(R+2r)/(R+r)
= (R+2r)mE²2(R+r)B²L²。
⚠️ 易错点1：v₀ = E/(BL) 的来源
开关 a 接通足够久后棒匀速，此时电流为零、安培力为零，棒的动生电动势恰好等于电源电动势 E = BLv₀。这是后续两问的公共初态，必须先求出。
⚠️ 易错点2：(2)中动量是“减速”
接 b 后棒仍在运动（BLv₀ > U），电流方向使安培力阻碍运动，动量定理应为 −BLq = m(v−v₀)。若误写为正号会得到 v 大于 v₀，与“充电制动”矛盾。
⚠️ 易错点3：(3)的 Q 是“棒上”热量
题目只问导体棒（电阻 r）上产生的焦耳热，不是回路总热量。它由两部分组成：a 阶段棒已发热 Q₁，以及 c 阶段棒在回路中按 r/(R+r) 比例分得的 Q₂。总热量 Q=(R+2r)mE²/[2(R+r)B²L²] 正是这两部分之和。
💡 总结：动量定理 + 能量守恒
电磁感应中棒受变力时，优先用“动量定理的累积形式” B·Δq = mΔv（其中 Δq 为流过棒的电荷）绕过复杂的速度积分；能量问题则用“电源输出/动能增量/焦耳热”守恒。储能器 U=kq 本质是新模型电容器，q 直接由电压读出。
