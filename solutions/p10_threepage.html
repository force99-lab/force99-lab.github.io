匀强电场中的等速率曲线（椭圆族）

2026年重庆高考 · 物理第10题（多选）

如图所示，xOy 平面内充满沿 y 轴正方向的匀强电场，原点 O 处的粒子源以不同的初速度沿 x 轴方向发射多个比荷为 k 的带正电粒子。将粒子在电场中运动速率相同的位置连接起来，得到一条平滑闭合曲线。图中曲线 a、b 对应的速率分别为 v、√2 v，直线 y = x 与 a、b 交于 M、N 两点。若 a 与 y 轴交于 (0, L) 点，不考虑粒子重力及粒子间相互作用，则（　　）

求：

  1. A. 电场强度的大小为 v²2kL
  2. B. M、N 两点间的电势差为 2v²5k
  3. C. 经过 a 最右端的粒子初速度大小为 v2
  4. D. 粒子从 O 到 M 所用时间与从 O 到 N 所用时间之比为 1 : 2

③ 交互式解题

比荷 k = q/m
电场 E 沿 +y（匀强）
曲线 a 速率 v，过 (0, L)
曲线 b 速率 √2 v

逐步求解（点击展开答案）

第(1)步：粒子的运动与任意位置速率
粒子从 O 以初速 v₀ 沿 +x 射出，受沿 +y 的恒定电场力，加速度 ay = kE：
x = v₀t ，y = ½ kE t² ，vy = kE t
任意位置速率：v² = v₀² + (kE t)² = v₀² + 2kE y（用 t = √(2y/kE) 消去时间）。
第(2)步：证明“等速率曲线”是椭圆
由 y = ½kE x²/v₀² 得 v₀² = kE x²2y ，代入速率式并令 v 为常数：
kE x²2y + 2kE y = v²  ⇒  x² + 4y² − 2v²kE y = 0
整理得 x² + 4(y − c)² = 4c²，其中 c = v²4kE 。
这是椭圆：中心 (0, c)、上顶点 (0, 2c)、最右端 (2c, c)，且过原点 O。
第(3)步：判定 A、B 两项
A：曲线 a 的上顶点 (0, 2c) 即 (0, L) ⇒ ca = L/2 ⇒ v²4kE = L/2 ⇒ E = v²2kL　✔ A 正确
B：令 x = y 代入椭圆 ⇒ 5x² − 8cx = 0 ⇒ x = 8c5 。
M：ca = L/2 ⇒ yM = 8c5 = 4L5；N：cb = 2ca = L ⇒ yN = 8L5 。
沿 E 方向电势差 ΔU = E(yN − yM) = E·4L5 = 2v²5k　✔ B 正确
第(4)步：判定 C、D 两项（证伪）
C：a 最右端 (2ca, ca) = (L, L/2)，该处 v₀² = kE x²2y = kE·L = v²2 ⇒ v₀ = v√2 ≠ v2　✘ C 错误
D：t = x/v₀。M 处 v₀² = 2kEL5 = v²/5 ⇒ v₀ = v/√5，tM = 4√5 L5v ；
N 处 v₀² = 4kEL5 = 2v²/5 ⇒ v₀ = v√(2/5)，tN = 8√5 L5√2 v 。
tM : tN = 1 : √2 ≠ 1 : 2　✘ D 错误

结论：正确答案为 A、B。

⚠️ 易错点1：等速率曲线 ≠ 粒子轨迹
“速率相同的位置连成的曲线”是不同粒子在同一速率下位置的集合，形状是椭圆；而单个粒子的轨迹是抛物线。二者完全不同，切勿把 a、b 当作某条运动轨迹。
⚠️ 易错点2：电势差只与 y 差有关
匀强电场沿 +y，电势差 ΔU = E·Δy，只与两点沿场方向的 y 坐标之差有关，与水平位移 x 无关。不要误用 ΔU = E·(M、N 两点的距离)。
⚠️ 易错点3：最右端 ≠ 初速度最大处
C 项是典型陷阱。椭圆最右端 (2c, c) 处速率恰为 v，须回到 v₀² = kE x²/(2y) 计算，得 v₀ = v/√2（不是 v/2）。想当然取一半即错。
💡 总结1：等速率曲线通式
匀强电场中“等速率点”恒为椭圆：
x² + 4(y − c)² = 4c² ，c = v²4kE
中心 (0, c)、上顶点 (0, 2c)、最右端 (2c, c)，过原点 O；速率越大 c 越大（c ∝ v²）。
💡 总结2：直线 y = x 的快捷结论
直线 y = x 与椭圆交于 O 及一点，该点坐标 x = y = (8/5)c。于是“同一方向观察两条曲线”的纵向间距之比恒为两 c 之比；本题 cb = 2ca，故 yN − yM = 4L/5，一步得 ΔU = 2v²/(5k)。
