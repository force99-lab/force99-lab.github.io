原题再现

第43届预赛 · 计算题第15题（40分）
如图15a，一固定的斜面长度为 L，与水平面的夹角为 θ，斜面底端固定有垂直于斜面的薄挡板；将一个可视为质点的滑块置于斜面顶端，在 t = 0 时刻由静止释放滑下。滑块与斜面的动摩擦因数为 μ，μ < tanθ。滑块与挡板之间发生弹性正碰。重力加速度大小为 g，忽略空气阻力。每次碰撞的持续时间极短。
（1）求物块与挡板首次碰撞的时刻 t1。
（2）求物块停止运动的时刻 T1。
（3）如图15b，若在 t = Δt 时刻（Δt < T1 − t1），在斜面顶端再由静止释放一个同样的滑块，两滑块间的碰撞是弹性的。求两滑块都停止运动的时刻 T2。

物理过程拆解

往复衰减演示（点击"下一页"离开即暂停；参数为示意值）
两个加速度（关键第一步）：
下滑：a = g(sinθ − μcosθ) > 0（因 μ < tanθ ⟺ μcosθ < sinθ）
上滑：a′ = g(sinθ + μcosθ)，减速的加速度大小
每次与挡板弹性正碰：速率不变、方向反转。

三问的破题思路

第(1)问：匀加速直线运动（点击展开）

从顶端静止下滑 L：L = ½at12，直接解出 t1。送分问。

第(2)问：往复衰减 = 等比级数（点击展开）

每次碰挡板后上滑（减速度 a′）、再下滑（加速度 a）。由"上滑距离 = 下一段下滑距离"得每段速度按公比 r = √a/a′ 递减，各段时间也按 r 递减——把所有段求和化为无穷等比级数。

易错：上升用 a′、下降用 a，两段加速度不同，不能直接套"竖直弹跳"的对称结论。

第(3)问：速度交换 = "彼此穿透"（点击展开）

等质量弹性碰撞必交换速度。可把两滑块想象成互相"穿透"、各自独立运动——系统的每个"速度状态"只是换了载体。于是全部停止的时刻 = 两个"独立滑块"停止时刻的较晚者 = Δt + T1。

第(1)(2)问 · 规范解答

图15a（原题图）
令
a = g(sinθ − μcosθ)
a′ = g(sinθ + μcosθ)
r = √a/a′ < 1
① 第(1)问：静止下滑 L，匀加速L = ½at12 ⟹ t1 = √2Lg(sinθ−μcosθ)
② 首次到达挡板速率 v1 = at1；碰后以 v1 上滑第1次上滑时间 t′1 = v1/a′ = (a/a′)t1 = r2t1；上滑路程 s′1 = v12/(2a′)
③ 第2次下滑：由上滑距离 = 下滑距离，回到挡板速率 v2 = r·v1v22 = v12 − 2a′s′1 + 2as′1 = v12(1 − (a′−a)/a′) = r2v12；∴ t2 = v2/a = r·t1，t′2 = r2t2…… 每段按 r 递减
④ 无穷等比级数求和（T1 为全部下滑段 + 上滑段之和）T1 = (t1 + t′1) + (t2 + t′2) + … = (t1 + t′1)(1 + r + r2 + …) = t1 + t′11 − r
∵ t′1 = (a/a′)t1 ∴ T1 = t1 · 1 + a/a′1 − √a/a′
⑤ 代入 t1、a、a′ 得最终结果（与官方评分标准式16一致）T1 = √2Lg(sinθ−μcosθ) · 1 + a/a′1 − √a/a′，其中 a = g(sinθ−μcosθ)，a′ = g(sinθ+μcosθ)
因 μ → 0 时 r → 1，T1 → ∞（永远不停），结果自洽 ✓
⚠ 易错警示

① 上下滑加速度不同：上升 a′ = g(sinθ+μcosθ)，下降 a = g(sinθ−μcosθ)，两段不对称。

② 级数公比是 r = √a/a′（速度比），不是 (a/a′)。

③ 求和对象是"时间"，不能用"总路程法"直接给时间——总路程 s = L·tanθ/μ 只用于能量校验。

✔ 量纲与极限自检（点击展开）

① 量纲：t1 乘无量纲因子 (1+a/a′)/(1−r)，结果为时间 ✓

② μ → 0：r → 1，T1 → ∞，与"无摩擦永不停"一致 ✓

③ μ ↑（趋近 tanθ）：r → 0，T1 → t₁(1+0)/(1−0)·… 第一段上滑即近乎停住，T1 → t₁ + 0，合理 ✓

第(3)问 · 规范解答

图15b（原题图）
条件
Δt < T1 − t1：第二滑块释放时，第一滑块尚未停（保证两滑块在斜面上相遇并发生碰撞）。
① 等质量弹性碰撞：动量守恒 + 动能守恒mu + mv = mu′ + mv′　，　½mu2 + ½mv2 = ½mu′2 + ½mv′2
联立解得 u′ = v，v′ = u —— 两滑块恰好交换速度
② "彼此穿透"等价图像碰撞时间极短，交换速度后两滑块的运动，与"两滑块互相穿透、各自独立运动、互不影响"完全相同——每个速度状态只是换了载体。
③ 各自独立运动的停止时刻滑块1：T1；滑块2（推迟 Δt 释放，运动规律相同）：Δt + T1
④ 全部停止时刻 = 较晚者T2 = Δt + T1 = Δt + √2Lg(sinθ−μcosθ) · 1 + a/a′1 − √a/a′（与官方评分标准式21一致）
⚠ 易错警示

① 试图逐次分析两滑块间无数次碰撞——陷入泥潭。正解是穿透等价 + 时间平移，一步到位。

② 忘记条件 Δt < T1 − t1 的作用：保证释放第二滑块时第一滑块仍在运动途中，二者一定相遇碰撞（否则第二滑块可能碰不到）。

③ 误以为两滑块碰撞会损失能量——弹性碰撞无机械能损失，摩擦才耗能。

✔ 想不通时的检验（点击展开）

极限 Δt → 0：两滑块几乎同时同地释放，始终贴在一起同步运动，等价于一个 2m 的滑块（弹性碰模型不改变结论），T2 → T1，与公式一致 ✓

能量视角：两滑块总机械能 2mgLsinθ 全部被摩擦耗散，总路程 2L·tanθ/μ；碰撞不耗能，不影响时间的"接力"结构。

方法沉淀 · 一题三法

① 往复衰减问题通法

下滑、上滑加速度不同的弹跳（斜面挡板、皮球漏气等）：找出每段速度（时间）的公比 r，把总时间/总路程写成无穷等比级数求和。

本题：r = √a/a′，T1 = t1(1+a/a′)/(1−r)。

能量只用来"校验"总路程 s = L·tanθ/μ，别硬套求时间。

② 等质量弹性碰撞 = 速度交换

动量、动能双守恒 ⟹ u′=v，v′=u。多次碰撞问题可视为各"速度状态"在滑块间接力传递，等效于互相穿透、独立运动。

这是第(3)问的唯一破题点，避免逐次碰撞计算。

③ 三个自检习惯

① 极限检验：μ→0 应发散、Δt→0 应退化为单滑块。

② 量纲检验：结果必为时间量纲。

③ 条件翻译：Δt < T1−t1 ⇔ 两滑块必相遇。

答案汇总：t1 = √2Lg(sinθ−μcosθ)　　T1 = t1·1 + a/a′1 − √a/a′　　T2 = Δt + T1
