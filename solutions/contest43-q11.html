攀岩弹性绳：机械能守恒导代数方程 · 最大拉力 · H→0 简谐极限 · 冲坠系数

原题再现

第43届预赛 · 计算题第11题（40分）
在攀岩运动中，攀登者通过绑定弹性绳索防止坠落受伤。如图11a，攀岩时，跨过保护点（相当于光滑定滑轮）的弹性绳将攀登者与固定端连接，固定端和攀登者之间的绳索未受力时自然长度为 L。设弹性绳的劲度系数为 CL，其中 C 为常量。一质量为 m 的攀登者，在保护点上方发生坠落，此时绳索未张紧。在自由坠落距离 H 后，绳索开始伸长。忽略空气阻力和人的横向摆动，重力加速度大小为 g。不计绳的质量。
（1）试导出绳的最大伸长 ΔL 所满足的代数方程；
（2）求绳对攀登者的最大拉力的大小 F 与 H 的关系；
（3）当 H 趋于 0 时，F 为何值？在此极限下，绳索从最大伸长恢复到原长所用的时间 t 为多少？
（4）定义冲坠系数为 f = HL。取 C = 2.0×104 N·m，m = 60 kg，g = 9.8 m/s2。人能承受的最大拉力为 12 kN，求人承受最大拉力时对应的冲坠系数 fC。

物理过程拆解

两阶段（绳只在伸长时出力）：
① 自由落体：绳松弛，只受重力，下落 H 后速度 v = √2gH；
② 绳张紧：F绳 = k·ΔL（胡克定律，k = C/L），人是"竖直弹簧振子"——绕新平衡位置 mg/k 做简谐式的往复（绳不能压缩，故只往复"下半周"，但能量关系不变）。
破题钥匙：全程只有重力和弹力做功 ⟹ 机械能守恒直接给 ΔL 的代数方程；最大拉力 F = kΔLmax；H→0 的极限就是"竖直弹簧振子"，最大拉力必为 2mg——先用守恒做一般情形，再用极限检验。

第(1)(2)问 · 规范解答

图11a（原题图）
关系备查
k = C/L
张紧时伸长 x，绳拉力 F = kx
全程机械能守恒
① (1) 取最低点：动能变化为零，重力势能减少 mg(H+ΔL)ΔEg = 0 − mg(H+ΔL)；ΔE弹 = ½k(ΔL)2 = ½(C/L)(ΔL)2
② 机械能守恒 ⟹ ΔL 的代数方程½(C/L)(ΔL)2 − mgΔL − mgH = 0（官方式4）
即 ½k(ΔL)2 = mg(H+ΔL)
③ (2) 解方程取正根（ΔL > 0）ΔL = mgLC[1 + √1 + 2CHmgL]（官方式7）
④ 最大拉力 F = kΔLF = (C/L)·ΔL = mg[1 + √1 + 2CHmgL]（官方式9）——F 随 H 单调增大
⚠ 易错警示

① 高度关系：最低点在保护点下方 ΔL 处，重力势能减少的是 mg(H+ΔL) 而非 mgH——最大丢分点。

② 弹性势能从绳张紧时刻才开始积累：½k(ΔL)²，不是 ½k(H+ΔL)²。

③ 题目要求"代数方程"，不必硬解出 ΔL——写出②式即得分。

✔ 自检（点击展开）

① H=0：ΔL = 2mg/k（绳从原长被静置的"质量块"拉到平衡位置下方 2 倍振幅处），F = 2mg，与第(3)问极限一致 ✓

② F 单调性：H 越大坠落动能越大，ΔL 越大，F 越大——冲坠越危险，符合直觉 ✓

第(3)(4)问 · 规范解答

图11a（原题图）
第(3)问的物理图像
H→0：人恰在绳原长处静止释放
⟺ 竖直弹簧振子从原长静止释放
⟹ 做简谐振动，振幅 A = mg/k
最低点伸长 2mg/k，F = 2mg
① (3) H→0 极限F = mg[1 + √1+0] = 2mg——正是竖直弹簧振子最大拉力（从此后的运动是简谐振动也可确认）
② 从最大伸长恢复到原长 = 1/4 个简谐周期T = 2π√m/k = 2π√mL/C
t = T/4 = π2√m/C（官方式13）
③ (4) 由第(2)问反解冲坠系数F/(mg) − 1 = √1 + 2CHmgL ⟹ 2CH/(mgL) = (F/(mg) − 1)2 − 1
fC = HL = mg2C[(F/(mg))2 − 2F/(mg)] = mg2C[(F/(mg) − 1)2 − 1]
④ 代入数据：C=2.0×104 N·m，m=60 kg，g=9.8 m/s2，F=12 kNF/(mg) = 12000/588 = 20.4
fC = 5884×104×[(20.4−1)2 − 1] ≈ 0.0147×415 ≈ 5.5（与官方答案一致）
⚠ 易错警示

① 展开平方：(F/(mg)−1)² − 1 = (F/(mg))² − 2F/(mg)，误写成 (F/(mg))² − 1 会算出 6.1 而非 5.5。

② t = T/4 的理由：简谐振动从最大位移（最低点）到平衡位置（原长 z=0 处？注意绳"原长"即振子的平衡位置上、伸长为零处）——用简谐的对称性，不要解超越方程。

③ f_C 无量纲才对：mg/(2C) 的单位是 m，乘无量纲括号 → 无量纲 ✓（H/L 也是无量纲）。

✔ 物理背景（点击展开）

冲坠系数 f = H/L 是攀岩安全的核心指标：坠落距离相对绳长越大，绳吸收冲击越"吃力"，峰值拉力越大。UIAA 规定 f 不得超过 2。

本题结论 F = mg(1+√(1+2fC/(mg)))：绳越"软"（C 越小），同样冲坠下 F 越小——保护器材的本质是"以更大的形变换更小的力"。

方法沉淀

① 守恒法立代数方程

弹簧+重力多阶段问题，全程机械能守恒一步到位：½k(ΔL)² = mg(H+ΔL)。

列式前先画"始、末"两个状态，标清每个势能的零点与变化量。

② 极限即特例

H→0 不是平凡情形，而是竖直弹簧振子标准模型：F=2mg、t=T/4=（π/2）√(m/C)。

一般结果代入极限检验，是竞赛答题的自检利器。

③ 由解析式反解参数

第(4)问不重新受力分析，直接把 F(H) 反解为 H(F)——"正问题反着用"。

注意平方展开：√(1+X) = F/(mg)−1 ⟹ X = (F/(mg)−1)²−1，展开别漏"−2F/(mg)"项。

答案汇总：½(C/L)ΔL² − mgΔL − mgH = 0　　F = mg[1+√1+2CHmgL]　　F→2mg，t = π2√m/C　　fC ≈ 5.5
