骨架未动，血肉已换

第42届与第43届全国中学生物理竞赛初赛 · 专业化对比与备考重构

骨架未动，血肉已换——第42届与第43届全国中学生物理竞赛初赛的专业化对比与备考重构

副题：从"考你会不会算"到"考你有没有物理直觉"　数据基准：第42届（2025-09-06，9:00–12:00）、第43届（2026-09-05，9:00–12:00），均全国统一命题、满分400、时长3小时。

引言

第42届（2025年9月6日）与第43届（2026年9月5日）全国中学生物理竞赛预赛，均由全国竞赛委员会统一命题，满分400、时长3小时、16题（选择5+填空5+计算6）的拓扑结构完全一致。命题框架的稳定，恰好给"对比"提供了一组干净的对照组：在卷面不变的前提下，两届试题在能力导向上的差异，暴露了命题理念的迁移。

结论先行：两届初赛"骨架"纹丝不动——结构、题型、分值、核心数学工具、守恒律思维全部守恒；但"血肉"正在发生范式转移：从"精确建模+硬计算"走向"数量级直觉+前沿情境剥离+小量近似主导"。命题正从"考你会不会算"转向"考你有没有物理直觉与建模勇气"。不变的是第一性原理能力，变的是能力的外显形态。

一、恒定之锚：哪些能力要求没有变

1.1 试卷拓扑结构恒定（对照表）

结构零变化，意味着"答题节奏管理""填空速算保分""计算题分步拿分"的策略两届通用，无需重学。

1.2 核心数学武器恒定

两届都依赖同一组数学工具：

  • 量纲分析：42届选1（小孔流水 $t\propto\sqrt{H}$）即用；43届选5（引力波功率指数）更把它升格为独立得分点。工具本身未变。
  • 矢量几何与坐标系变换：42届算12要求"旋转坐标系45°使 $\mathbf B$ 沿新基矢，证沿磁/垂直磁运动独立"；43届算12（磁镜）、算16（光学曲率）同样依赖矢量分解。
  • 守恒律（能量/动量/角动量）：42届算13（滑块-斜面）、算16（卫星分裂定轨）；43届算11（攀岩绳）、算13（月球宇宙速度）均为守恒律主场。
  • 近似展开（小量/泰勒）：两届都大量出现，43届更显式（见第二节）。

1.3 "模型拼贴"范式恒定

两届都擅长把多个标准模型揉进一题：

  • 42届算14 = 弹簧简谐振动 + 电场匀加速 + 完全非弹性碰撞 + 新平衡位置简谐（四件套）；
  • 43届算11 = 自由落体 + 弹性势能 + 简谐振动 + 冲坠系数工程定义（四件套）。

命题都要求"识别子模型→建立耦合方程"，这一底层能力要求未变。

1.4 实验思想与定量估算席位恒定

42届填9（泡沫箱热传导，Fourier定律直接套用）、43届算16（玻璃块测曲率，从装置抽象光学模型）都占填空/计算席位，说明"实验素养"始终是初赛的硬指标，只是呈现方式升级（见 2.6）。

二、变动之浪：创新与升级

2.1 量纲分析 + 数量级估算：从配角升为主角

42届选1用数量级选出 B（高度×4→时间×2），但仅是单点；43届将此能力系统化、高频化：

  • 选1（树叶影子池底移动速度）：答案落在 $\mu\mathrm{m/s}$ 量级，需结合视深 $h'=h/n$ 与太阳角速度估算，四个选项横跨 $\mu\mathrm{m/s}$ 到 $\mathrm{mm/s}$ 两个数量级（官方答案 A）；
  • 选5（双黑洞引力波辐射功率）：给出 $P=k\,G^{a}c^{\beta}(Mm)^{2}/(M+m)^{\gamma}$，直接要求由量纲确定指数关系，官方答案为 ABD（即 $2a+\beta-\gamma=3$、$3a-\gamma=2$、$a=-\gamma/3$）。量纲分析首次成为"多选全对才满分"的独立考点；
  • 填7（大气绝热递减率）：由静力平衡+理想气体+绝热关系，得每上升 1 km 降温约 9.8 K（干绝热递减率），是"估算+物理常数"的组合；
  • 填6（水波波前公切线）：$\cos\theta$ 由 $\Delta t,d,\lambda,g$ 组合，典型"几何+量纲"估算。

判据：43届选择/填空里"最接近""估算""量级"类题显著多于42届，且不再给足精确数值让你"算"，而是逼你"估"。

2.3 小量近似 / 绝热不变量成为区分度核心

43届多处显式标注"很小""近似"：

  • 填6 "满足 $\Delta t\ll d$"、波前公切线小角；
  • 填7 绝热近似（不同高度空气无热传递）；
  • 算12 磁镜：明确"磁场沿 $z$ 缓慢增强""回旋周期 $\ll$ 漂移周期""粒子可视为近似闭合回旋"，要求学生识别磁矩 $\mu=mv_\perp^{2}/(2B)$ 守恒这一绝热不变量，推出反射条件 $\sin\theta_0=\sqrt{B_0/B_{\max}}$；
  • 算16 小角近似曲率半径。

这要求"敢近似、会近似"，与42届"算12 旋转分解后精确积分"形成方法论差异：42届重解析、43届重近似。

2.4 电磁学概念深度上探

42届电磁计算题（算12电磁场粒子、算15电磁感应梯形回路）是"标准进阶"；43届电磁（算12磁矩守恒、算14电场随 $z$ 变+磁场耦合漂移、填9电容器+线圈+二极管综合）进入等离子体物理 / 回旋加速器物理层面，概念更深、更"现代"。

2.5 天体 / 航天权重上升，力学主场被稀释

42届天体仅出现在选8（近地卫星偏角）、算16（卫星分裂）；43届算13直接考月球三种宇宙速度（含地月系统逃逸的第三宇宙速度拼接），引力 / 航天占比明显增大，传统"滑块斜面"类纯力学计算题减少。

2.6 实验：从"套公式"到"建模型"

  • 42届填9：给 Fourier 定律 $H=kS\Delta T/d$，直接代入数字；
  • 43届算16：给"激光器 + 玻璃块 + 拱柱弧 AB"，要你自己抽象出折射偏角、入射角、小角近似，最后求曲率半径。

前者考"会不会代公式"，后者考"能不能从装置写出方程"——实验建模能力要求实质性升级。

三、精准对照：三组题看不变与变动

对照① 量纲的"守"与"升"

  • 42届选1：小孔流水，$t\propto\sqrt{H}$，$H\times 4\to t\times 2$（选 B）。内核 = Torricelli + 量纲。
  • 43届选5：引力波功率指数，由 $[P]=[G]^{a}[c]^{\beta}[M]^{4-\gamma}$ 解出 $a=1/3,\ \beta=4/3,\ \gamma=-1$，关系 ABD 成立。

→ 量纲工具守恒，但其"独立计分权重"在43届飙升。

对照② 守恒 / 近似的"解析"与"绝热"

  • 42届算12：旋转坐标系，证明沿磁 / 垂直磁独立，精确解滚轮线。
  • 43届算12：磁镜，用"回旋 $\ll$ 漂移"近似，导出 $\mu$ 守恒 $\to$ 反射。

→ 同是电磁+坐标系，42届考分解技巧，43届考"识别不变量"的物理直觉。

对照③ 实验的"代"与"建"

  • 42届填9 vs 43届算16（见 2.6）。

→ 实验从操作题升为建模题。

精准算例（说明"内核不变、包装在变"）：43届选2（BNCT）给出核反应 $^{10}\mathrm{B}+{}^{1}\mathrm{n}\to{}^{7}\mathrm{Li}+{}^{4}\mathrm{He}$，质量亏损

$$\Delta m=(10.0129+1.0087)-(7.0160+4.0026)=0.0030\ \mathrm{u}$$

释放能 $Q=0.0030\times931.5=2.79\ \mathrm{MeV}$。反应前中子动能可忽略，由动量守恒两产物动量等大反向，故 $E_{\mathrm{He}}/E_{\mathrm{Li}}=m_{\mathrm{Li}}/m_{\mathrm{He}}$，得

$$E_{\mathrm{He}}=Q\cdot\frac{m_{\mathrm{Li}}}{m_{\mathrm{Li}}+m_{\mathrm{He}}}=2.79\times\frac{7.0160}{11.0186}\approx1.78\ \mathrm{MeV}$$

选 C。这道题的"包装"是核医学，内核却是高一就学的"质量亏损+动量守恒"——正是两届共通的守恒律能力，被43届用前沿情境重新包装。

四、专业化备考重构（可操作）

基于以上对比，给出八条可执行的训练路径：

  1. 第一性原理反应：见题先问"守恒量？对称性？不变量？"，而非"这是哪类题型"。43届选5、算12都惩罚"套题型"思维。
  2. 量纲 + 数量级刻意训练：每日3道估算（如"太阳光压数量级""人体热功率"），训练到选项能秒排。这是43届最大增量。
  3. 小量展开规范化：熟记泰勒、小角、$(1+x)^{-1}\approx1-x$、绝热近似；主动标记题干"很小""近似"信号。
  4. 坐标系变换与矢量几何：复练42届算12、43届算12/16的分解套路。
  5. 模型拼贴拆解：把复合题拆子模型（43届11 = 自由落体 + 弹性势能 + 简谐 + 冲坠定义），先列子模型再耦方程。
  6. 前沿情境剥离：读科研新闻，练习"剥包装找核心方程"。BNCT 内核 = 质量亏损；引力波内核 = 量纲；磁镜内核 = $\mu$ 守恒。
  7. 计算耐力模拟：6道40分计算连做，限时3小时，训练分步拿分与草稿管理。
  8. 实验建模转型：从"代公式"转"给装置写方程"，常练"由图建模"。

四大误区：

  • 只刷题型不练直觉 → 43届选1/选5栽；
  • 怕近似、追精确 → 43届填6/算12要求敢近似；
  • 电磁记结论不究不变量 → 43届算12磁矩守恒；
  • 忽视数量级 → 选1 $\mu\mathrm{m/s}$ 与 $\mathrm{mm/s}$ 差50倍，估算错全错。

结语

两届初赛的对照揭示了一条清晰的主线：物理竞赛初赛正在从"解题术"走向"物理直觉"。卷面的恒定，保证了扎实基本功永不过时；血肉的更换，提醒我们——未来的优胜者，不是算得最快的人，而是最先看清"这道题的物理本质是什么"的人。对备考者而言，真正的专业化训练，是把第一性原理、数量级直觉、近似勇气，练成不需要思考的肌肉反应。

（本文试题与答案数据来自第42届、第43届全国中学生物理竞赛预赛官方试题及评分标准公开版本，对比分析为作者专业化解读。）
