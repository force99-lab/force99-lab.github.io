物理知识归纳

取竖直向下为正方向，以释放点为原点记位移 s； 弹簧上端自然位置在 s = h₀，接触后压缩量 x = s − h₀。

① 四阶段与合力

自由落体（s < h₀）：a = g，F = mg。
接触压缩：a = g − (k/m)x，F = mg − kx。
接触回弹：同一式，x 减小，a 由负回到 g。
空中弹起：仅重力，a = −g（向上减速）。

② 最大压缩 —— 最常见的错

由能量守恒（接触过程无损）：½mv₀² + mgx = ½kx²，即

x_max = x_eq + √(A² + x_eq²)，　x_eq = mg/k，A = v₀/ω

其中 ω = √(k/m)。注意：简谐运动的振幅 A 与 x_max 不是一回事 —— 简谐中心是平衡位置 x_eq， 而不是接触点 x = 0。只有 x_max = A 才能写成 v₀/ω。

③ 两幅图像

F–s 图：空中段是 F = mg 的水平线；接触段是斜率 −k 的直线，与横轴交点即平衡位置 s = h₀ + x_eq。每次撞击都沿同一条斜线走过，只是范围逐次变短。

v–t 图：三段斜率都是 g（自由落体正、接触段为余弦弧但单调下降、弹起段为负）； 每次离开弹簧速率乘 e，故振幅等比衰减，最终停于 x_eq。

高考要点　① 最大压缩与最大弹力：F_max = k·x_max 常远大于 mg （默认参数下约 7.3 mg）—— 因为压缩量小但劲度大。 ② 全过程可用能量守恒求任意时刻速度：½mv² + ½kx² + mgh = 常数。
易错
✗ 把最大压缩写成 v₀/ω —— 漏了重力势能，正确答案多出 x_eq 一项。
✗ 认为最大弹力等于 mg —— 平衡位置处合力为零，但那是中间时刻，最大弹力在最大压缩处。
✗ 认为接触段 v–t 斜率仍是 g —— 接触段 a = g − (k/m)x < 0，且随 x 增大而变陡。
✗ 认为小球最后停在弹簧原长处 —— 静止在平衡位置 x_eq，此时合力为零。
模型说明　弹簧质量不计；接触损耗用一个恢复系数 e 描述 （离开弹簧时速率变为 e·v）。e = 1 时能量无损、等幅弹跳。
