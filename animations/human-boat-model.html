人船模型 · 动量守恒

船静止于水面 · 不计水阻 · 人从船头走向船尾

人的质量 m70 kg
船的质量 M300 kg
船长 L5.0 m
步行相对速率 U1.2 m/s
播放速度1.00×

核心规律

水平方向不计水阻 → 系统所受合外力为零，动量守恒。初态静止，故任一时刻

m·v_人 + M·v_船 = 0  ⇒  v_船 = −(m/M)·v_人

人与船相互作用为内力，系统质心水平位置不变（动画中央虚线即质心所在，始终不动）。

位移关系（走完全程）

人与船相对位移等于船长 L：Δx_人 − Δx_船 = L
动量守恒约束：m·Δx_人 + M·Δx_船 = 0
联立得 Δx_人 = M/(m+M)·L，Δx_船 = −m/(m+M)·L

即：人走得越远，船退得越多；船越重，船退得越少。两者位移大小之比 |Δx_人| : |Δx_船| = M : m。

易错警示

✗ 认为“人向前走、船不动”——错。无外力时质心必静止，船必向反方向退。

✗ 把船的位移当成 L——错。人相对船走 L，但船自身后退，人相对地面只前进 M/(m+M)·L。

提示：动画下方位移条中橙色（人）与青色（船）两段长度之和恰好等于船长 L；速度箭头长度实时反映速度大小与方向。
