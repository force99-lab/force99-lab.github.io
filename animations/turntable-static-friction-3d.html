物理知识归纳

① 向心力的来源
物块随圆盘做匀速圆周运动，需要指向圆心的向心力。物块相对圆盘静止（未滑动）时，该力由圆盘对物块的静摩擦力提供（双物块细线情形由摩擦与细线张力共同提供）。 f = m·ω²·r  （指向圆心） 静摩擦是被动力：大小随所需向心力动态变化。
② 临界角速度与"先达最大、后反向"规律
静摩擦有最大值 f_max = μ·m·g，超过极限物块便相对圆盘滑动——沿径向滑出并相对盘面滞后转动（辐条从物块下"滑过"）。 单物块：ω_max = √(μg / r) 双物块：ω_max² = 2μmg / |m_B·r_B − m_A·r_A| 关键规律（谁先达极限）：离轴更远（或质量更大）使 m·r 较大的物块所需向心力更大，会先达到最大静摩擦力 f = +f_max 并封顶不再增大；离轴更近的物块所需向心力较小，其静摩擦力随 ω 增大由"指向圆心"逐渐减小、过零后渐变为"背离圆心（向外）"——这正是细线张力接管了大部分向心需求所致。近轴块反向的临界： ω_反² = μmg / (m_远·r_远 − m_近·r_近) 当 m_A·r_A = m_B·r_B（质量、半径均相等）时，分母为零——无论 ω 多大，两物块都不相对滑动。
③ 细线张力为什么"自动调节"（驱动反向）
细线张力是自动调节的约束力： 摩擦够用 m·ω²·r ≤ μmg 时，摩擦独自提供向心力，细线松弛（T = 0）。 摩擦不足 当某一侧 m·ω²·r 超过 μmg，该侧摩擦封顶于 +μmg，细线绷紧恰好补足缺口： T = m·ω²·r − μ·m·g  （需求更大的一侧决定张力） 由于两端张力相同，需求小的一侧被迫被往里拉，其摩擦 f = m·ω²·r − T 随之减小并反向（向外）。 因此 f–ω² 图上：需求大的一侧曲线在 +μmg 处走平（先封顶），另一侧曲线向下穿零——直观看到"由指向圆心渐变至背离圆心"。 m_A·r_A = m_B·r_B 时张力总能同时满足两侧 → 永不滑动，正是对称情形的物理本质。
④ 力的合成
每个物块所需向心力由张力（细线）+ 静摩擦（盘面接触）矢量合成：F_c = T + f。各贡献线性相加，与波的叠加同理。
⑤ 生活应用
洗衣机脱水：转速越高所需向心力越大，水分因附着力（类比摩擦）不足被甩出。 离心分离器：密度大的颗粒获得更大向心力被甩向外。 铁路弯道 / 摩天轮：静摩擦或支持力提供向心力，超过极限则侧滑。
