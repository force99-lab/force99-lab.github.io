② 物理知识归纳

核心思想：线圈在匀强磁场中绕垂直于磁感线的轴匀速转动，磁通量发生周期性变化，由法拉第电磁感应定律产生交变电动势。

磁通 Φ = Φm·cos(ωt)，　Φm = N·B·A
电动势 ε = −dΦ/dt = εm·sin(ωt)，　εm = N·B·A·ω
电流 i = ε/R = im·sin(ωt)，　im = εm/R
瞬时功率 P = i²R ∝ sin²(ωt) → 以 2 倍频率脉动，始终 ≥ 0

三个关键部件：① 磁体（提供匀强磁场）；② 线框（线圈）（切割磁感线产生感应电动势）；③ 金属滑环 + 电刷（把线圈中的交变电流引出到外电路，保持电流方向随转动连续变化）。

两个特殊位置的特点：

① 中性面（S⊥B，线圈平面与磁感线垂直的平面）：磁通量最大 Φm = BS，ΔΦ/Δt = 0 → ε = 0、i = 0，感应电流方向改变。
② 峰值面（S∥B，线圈平面与磁感线平行的平面）：磁通量最小 Φ = 0，ΔΦ/Δt 最大 → ε 最大、i 最大，电流方向不变。

频率关系：交流电频率 f 等于线圈每秒转动的圈数；线圈每转一圈，电动势完成一个完整正弦周期。

③ 交流电流的四值

① 瞬时值：交变电流的电动势、电流或电压在某一时刻的值，是时间的函数，随 t 按正弦变化 i = iₘ·sin(ωt)。
② 峰值（最大值）：交变电流的电动势、电流或电压所能达到的最大值 iₘ = N·B·A·ω/R。
③ 有效值：让交变电流与恒定电流分别通过大小相同的电阻，如果在交变电流的一个周期内它们产生的热量相等，就把这个恒定电流的电流 I、电压 U 叫作这一交变电流的有效值。
正弦式交流电的有效值与峰值关系：ε = εm/√2，　U = Um/√2，　I = im/√2 ≈ 0.707 im
④ 平均值：交变电流图像中图线与时间轴所围面积跟对应时间的比值（半周整流均值 Ī = 2iₘ/π ≈ 0.637 iₘ；整周平均恒为 0）。
