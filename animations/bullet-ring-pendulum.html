核心规律

① 完全非弹性碰撞（子弹嵌入木块，极短）：水平方向动量守恒，子弹与木块获得共速

v₁ = m_b·v₀ / (m_b + M)  （木块初速度，环尚未动）

② 摆起过程：细线张力为内力、导轨光滑 → 系统水平方向无外力，水平动量守恒；只有重力做功 → 机械能守恒。

P = (m_b+M+m_r)·Ẋ + (m_b+M)·L·θ̇·cosθ = m_b·v₀  （常量）
E = ½(m_b+M+m_r)Ẋ² + (m_b+M)ẊLθ̇cosθ + ½(m_b+M)L²θ̇² + (m_b+M)gL(1−cosθ)

高考重点

因圆心（圆环）可在导轨上自由滑动，系统质心以恒速向右漂移： v_cm = m_b·v₀ / (m_b+M+m_r)。故圆环持续右滑、木块相对圆环作摆动。

易错警示

✗ 认为“子弹动量全给了木块、圆环不动”——错。碰撞后系统水平动量守恒，但摆动中张力会把动量部分分给圆环，圆环始终在滑。

✗ 把圆环当作固定支点（普通单摆）。本装置支点是可动的，θ 与 Ẋ 强耦合，不能用 T=2π√(L/g)。

提示：导轨固定不动，圆环沿导轨向右滑动（滑到右端循环演示）——这是质心恒速漂移的可视化。
