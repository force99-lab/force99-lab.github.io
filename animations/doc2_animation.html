四球双弹簧弹性碰撞

2026 江苏卷 T16 · 计算题

如图所示，在光滑水平面上固定两个柱形光滑轨道，轨道上分别约束着只能沿轨道方向运动的两个小球 B 和 C，质量均为 (3/5)m。小球 B 和 C 通过弹性限度足够大的相同轻质弹簧与质量为 m 的小球 A 相连。初始时，两弹簧均处于原长。现有一质量为 M 的小球 D 以速度 v₀ 沿轨道方向与小球 A 发生对心弹性碰撞，碰撞时间极短，不计空气阻力。

  1. 求小球 D 与 A 碰撞后瞬间小球 A 的速度大小；
  2. 若发生碰撞后小球 D 不再与 A 碰撞，求每根弹簧所具有的最大弹性势能；
  3. 要使弹簧第一次恢复原长时，小球 D 与 A 恰好再次发生碰撞，求 m/M 的值。
mB=mC=3m/5 mA=m mD=M 初速 v₀ 轻质弹簧×2 光滑水平面·光滑轨道 对心弹性碰撞

引导式求解（点击问题查看推导）

下面用「引导式提问」带你一步步推导：每条先提出问题，点击展开答案与方程。
💡 引导(1)：D 与 A 的对心碰撞属于什么碰撞？应列哪两条守恒方程？
答：对心 弹性 碰撞 → 同时满足动量守恒与机械能守恒（向右为正）。 ⅓ 动量守恒：M·v_0 = M·v_D' + m·v_A
⅔ 机械能守恒：(1/2)Mv_0² = (1/2)Mv_D'² + (1/2)mv_A²
⅕ 联立解得：v_A = 2M/(M+m)·v_0   v_D' = (M-m)/(M+m)·v_0
💡 引导(2)：弹簧弹性势能何时最大？A·B·C 共速时速度多大？每根弹簧多大？
答：势能最大在 A、B、C 三者共速 时刻（相对速度为零）。 ⅓ 以 A·B·C 为系统，动量守恒：mv_A = mv_A' + (3/5)m(v_B+v_C)
由对称性 v_B=v_C，设共速为 v_c，则 mv_A = (11m/5)v_c → v_c = (5/11)v_A
⅔ 能量守恒（两根弹簧总势能 2E_p）：
(1/2)mv_A² = (1/2)(11m/5)v_c² + 2E_pmax
⅕ 每根 E_p = E_pmax/2，化简得：
E_p每根 = 6mM²v_0² / [11(M+m)²]
💡 引导(3)："再次碰撞"的物理条件是什么？怎样不求振动函数就得到位移关系？
答：条件是弹簧第一次恢复原长时 D 恰好追上 A（x_D=x_A）。 ⅓ 回避振动函数：对弹簧过程把动量守恒式同乘 Δt 再求和（离散积分）：
mv_A·t = m·x_A + (6/5)m·(x_B+x_C)
⅔ 结合对称性 x_B=x_C 与"恢复原长时再碰"临界条件分析，得：
m/M = 1/11
⚠ 易错点1：弹性碰撞方向判断
D碰后可能反弹(m<M)或继续前进(m>M)，必须用公式计算不能凭直觉。
⚠ 易错点2：弹簧势能最大时刻
势能最大在三者共速时刻（相对速度为零），不是A速度为零。
⚠ 易错点3：每根vs总势能
题目问每根弹簧的势能，能量守恒式中2E_p是总和，需除以2。
⚠ 易错点4：积分思想避求振动函数
第(3)问巧用动量守恒式同乘Dt求和转化为位移关系，避开求解具体振动函数。
📋 总结1：多体弹簧通法
分阶段（碰撞瞬间vs弹簧过程）；碰后用动量+能量；弹簧过程用系统动量+能量（含势能）；共速=势能极值点。
📋 总结2：对称性简化
B=C质量相等、弹簧相同→ v_B=v_C, x_B=x_C，三体简化为二体（A与等效质量6m/5的组合）。
📋 总结3：质心恒向右匀速
碰后 A·B·C 系统不受水平外力，质心始终向右匀速（图中◇标记）；各球只在质心附近振动，不会让质心向左。
