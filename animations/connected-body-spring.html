连接体 + 弹簧模型的综合分析

2026 陕晋青宁卷 · 第 10 题（多选）· 6 分

如图，物块 N、P、Q 的质量分别为 m、m、2m，Q 通过不可伸长的轻绳绕过两个固定轻质光滑定滑轮与 P 连接，P 与位于正下方的 N 用劲度系数为 k 的轻弹簧相连。初始时托住 N 和 Q，使弹簧处于原长，三个物块均静止。现同时无初速度释放 N 和 Q，运动中，物块均视为质点且不与滑轮相碰，不计空气阻力，弹簧始终在弹性限度内，弹性势能 Ep = ½kx²（x 为形变量），重力加速度大小为 g。则（　　）

  1. A. 释放后瞬间 Q 的加速度大小为 g3
  2. B. 释放后瞬间轻绳上的拉力大小为 mg
  3. C. 释放后 N 下降的最大距离为 3mg4k
  4. D. 释放后 N 的速度最大值为 g2√(3mk)
mN = m mP = m mQ = 2m 弹簧 k，初始原长 绳不可伸长（光滑定滑轮） Ep = ½kx² 释放瞬间 F弹 = 0 结论：A D

③ 交互式解题

模型：绳连接体（P、Q）+ 弹簧连接体（P、N）
约束①：P 上升多少，Q 就下降多少
约束②：弹簧形变量 s = xN + xP
关键①：形变量不能突变 ⟹ 释放瞬间 F弹 = 0
关键②：绳的拉力可以突变
关键③：由 ẍ = 3ÿ 且初值为零 ⟹ x = 3y
答案：A D

逐步求解（点击展开答案）

第 0 步：建模 —— 三个物体、两个约束

约束①（绳）：P、Q 由不可伸长的轻绳跨过两个光滑定滑轮相连，绳长不变 ⟹ P 上升多少，Q 就下降多少，两者速率、加速度大小相等、方向相反。

约束②（弹簧）：P、N 用轻弹簧相连 ⟹ 弹簧的形变量是两端相对位移的叠加。设 N 下降 x、P 上升 y，则弹

s = x + y

关键前提：弹簧的弹力由形变量决定，形变量不能突变，所以"释放瞬间"弹簧仍处于原长、弹力仍为零；而绳的拉力属于约束力，可以瞬间突变。

A、B 项：释放瞬间的瞬时加速度与绳的拉力

此刻 F弹 = 0。把 P、Q 看成"绳连接的整体"（两者 a 大小相同，Rope 张力是内力）：

2mg − mg = (m + 2m)·a ⟹ a = g3

方向：Q 向下、P 向上。故 A 正确。

再隔离 Q（取向下为正）：

2mg − T = 2m·a ⟹ T = 2mg − 2m·g3 = 4mg3
T = 4mg/3 ≠ mg ⟹ B 错误

顺带隔离 N：此刻 F弹 = 0，N 只受重力 ⟹ aN = g（瞬时呈"自由落体"式加速度）。

校验：隔离 P（向上为正）T − mg = m·(g/3) ⟹ T = 4mg/3，与整体法一致 ✓

关键一步：证明位移之比恒为 x = 3y

对 N（向下为正）与对 P、Q 整体（P 向上为正）分别用牛顿第二定律：

N：mg − ks = m·ẍ
P、Q：2mg − mg − ks = (m + 2m)·ÿ ⟹ mg − ks = 3m·ÿ

两式的左边都是 (mg − ks)，消去即得

m·ẍ = 3m·ÿ ⟹ ẍ = 3ÿ

又 t = 0 时 x = y = 0、ẋ = ẏ = 0，把 ẍ = 3ÿ 积分两次：

x = 3y　（整个运动过程恒成立）

于是弹簧的伸长量

s = x + y = x + x3 = 43x　⟹　x = 34s
能量守恒（把 N、P、Q、弹簧看成一个系统）

绳的拉力是内力、对系统做功之和为零；只有重力和弹簧弹力做功 ⟹ 系统机械能守恒。

重力做功：N 下降 x 得 mg·x；Q 下降 y 得 2mg·y；P 上升 y 失去 mg·y。合计

W = mg·x + 2mg·y − mg·y = mg(x + y) = mg·s

能量方程（注意 vN = 3vP、vQ = vP，动能可合并化简）：

mg·s = ½ks² + ½mvN² + ½mvP² + ½(2m)vQ²
　　　 = ½ks² + ½mvN² + 32mvP²
　　　 = ½ks² + 23mvN²　★

最后一步：½mvN² + (3/2)m·(vN/3)² = ½mvN² + (1/6)mvN² = (2/3)mvN²。

C 项：N 下降的最大距离

N 下降到最低点时 vN = 0；由 vN = 3vP 立刻可知此刻 vP = vQ = 0，整个系统都静止。

代入能量式 ★（动能项全部为零）：

mg·s = ½ks² ⟹ s = 2mgk
xmax = 34s = 3mg2k
3mg/(2k) ≠ 3mg/(4k) ⟹ C 错误

干扰项揭秘：3mg/(4k) 恰好是"N 速度最大时"的下降量（见 D 项），命题人正是用"差 2 倍"来设伏。

D 项：N 速度的最大值

N 的速度最大 ⟺ aN = 0 ⟺ mg − ks = 0：

s = mgk，此时 x = 34s = 3mg4k

代回能量式 ★（此刻动能最大）：

mg·s − ½ks² = 23m·vmax²
mg·mgk − ½k·(mgk)² = 12·m²g²k
vmax² = 34·mg²k ⟹ vmax = g2√(3mk)
D 正确　⟹　正确答案：A D
拓展：用"简谐运动"一眼看清 C 与 D 为何差 2 倍

把两式相加（s = x + y ⟹ s̈ = ẍ + ÿ）：

s̈ = mg − ksm + mg − ks3m = 43m(mg − ks)

即 s 做简谐运动：平衡位置 s₀ = mg/k，角频率 ω = √(4k/3m)。由初值 s = 0、ṡ = 0 得

s(t) = mgk(1 − cos ωt)　⟹　x(t) = 3mg4k(1 − cos ωt)
相位物理意义N 的下降量对应选项
ωt = π/2速度最大（aN = 0）3mg/(4k)D 的取值
ωt = π位移最大（vN = 0）3mg/(2k)C 应为这个

振幅是 3mg/(4k)、最大下降量是振幅的 2 倍；C 项给的是振幅（= 速度最大时的下降量），差了整整 2 倍。

周期 T = 2πω = π√(3mk)
⚠️ 易错点 1：把 N 也塞进"整体"
"整体法"只适用于加速度大小相同、方向沿绳的 P、Q。N 与 P 只由弹簧相连，弹簧可以让两端加速度不同（此刻 aN = g、aP = g/3），所以 N 必须单独隔离。
⚠️ 易错点 2：以为"拉力也会突变受阻"
弹簧的形变量不能突变 ⟹ 瞬间弹力不变（仍为 0）；而绳的拉力是约束力，可以瞬间突变（从 mg 突变为 4mg/3）。两者性质相反，最容易混。
⚠️ 易错点 3：凭感觉写 x = y 或 x = 2y
x = 3y 必须严格推导：由 m·ẍ = 3m·ÿ 得 ẍ = 3ÿ，再必须说明"t = 0 时位移与速度均为零"，两次积分才得到 x = 3y。少了这句，推导不成立。
⚠️ 易错点 4：C 项混淆"最低点"与"速度最大点"
3mg/(4k) 是速度最大时的下降量（aN = 0，ks = mg）；最低点的下降量是 3mg/(2k)（vN = 0，s = 2mg/k）。求"最大距离"要用能量守恒（v = 0），不是用 a = 0。
⚠️ 易错点 5：能量方程漏项
P 上升要"消耗"mg·y 的重力势能，Q 下降"提供"2mg·y，N 下降"提供"mg·x；三项合并恰好是 mg·s。若只写 mg·x 会算错；若忘了把 P、Q 的动能计入，也会算错。
💡 经验总结（弹簧系统两把钥匙）
① 位置（极值点）由动力学定：速度最大 ⟺ a = 0；位移最大 ⟺ v = 0。
② 极值的大小由能量守恒定：把系统看成一个整体，重力做功 + 弹力做功 = 动能 + 弹性势能。
③ 弹簧连接体的位移关系：由两式相减得加速度比值，再用"初值为零"积分；本例 ẍ = 3ÿ ⟹ x = 3y。
④ 绳连接体：沿绳方向 a 大小相同、方向相反，优先整体法（绳张力是内力）。
⑤ 简谐视角：全部合并成 s 的简谐运动后，"速度最大点"与"位移最大点"相差 π/2 相位，两者数值差 2 倍 —— 这是本题干扰项的来源。
⑥ 瞬时问题三原则：轻绳的力可突变、弹簧的力不可突变、杆的力可突变也可不变。
