抽桌面布，物块会掉下桌吗？

木纹桌上铺一条长桌布，物块放在布上。猛地向右抽动桌布（加速度 a），物块靠摩擦被带动。物块能否留在桌面，取决于摩擦能否让它"跟住"桌布——本质是 μmg 与 ma 的较量。

②物理知识归纳

情景：桌布长条铺在桌上，物块置于布上，向右猛抽桌布（加速度 a）。物块与桌布间动摩擦因数为 μ，物块右缘距桌右缘为 d，物块左缘距桌布左缘为 d₁。（取 g = 10 m/s²）

一、物块会不会相对桌布滑动？

抽布时物块因惯性"不想动"。若摩擦能带动物块一起以 a 加速，需要 ma；桌布能提供的最大摩擦力为 μmg。

临界：μmg ≥ ma ⇒ μg ≥ a → 物块跟住桌布，无相对滑动
反之 μg < a → 桌布从物块下"滑出"，出现相对滑动

二、分离时物块滑了多远？

滑动时物块受向右的摩擦 μmg，加速度为 μg；桌布加速度更大为 a。在地面参考系中，桌布相对物块以 (a − μg) 加速。当相对位移达到 d₁ 时，桌布刚好从物块下全部抽出（分离）。

分离时刻：tₛ = √[ 2d₁ / (a − μg) ]，此时物块位移 x₁ = ½·μg·tₛ²。分离后物块不会立即停止——它在桌面摩擦 μ（定值）下继续向右减速滑行，到 t = 2tₛ 才停下，总位移 X = μg·tₛ² = 2x₁。

三、判断是否掉落：

X < d → 物块总位移小于到桌边距离，抽布成功（留在桌面）；X ≥ d → 物块被拖过桌边，掉下桌面
临界加速度：a꜀ = μg·(1 + d₁/d)（刚好的分界）

易错提醒：① 抽得越快（a 越大）物块反而动得越少——这是"惯性"的妙用；② 物块加速度是 μg 而不是 a；③ 用地面参考系分别算位移最稳（等价于相对加速度 a − μg）；④ 桌布抽走后物块受桌面摩擦减速滑行一段才停下，不是瞬间静止。
